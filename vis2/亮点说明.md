## 人工智能 · 新质生产力 数据可视化网站亮点

该网站是一个完整的「AI 与新质生产力」长滚动数据看板：从「一句话定义」讲到产业规模、行业赋能、区域与全球格局，再讲要素如何流动、概念如何相连，最后收在结论与数据来源。全站 15 节、16 张自绘图表加 1 台可调参的生产力模拟器，中英双语、亮暗双主题，适合想用可视化快速理解这一主题的读者，也适合当「数据可视化」作业的完整样板。网页可在浏览器直接打开，**无需服务器、无需注册、无需联网**。

### 亮点一：一条主线贯穿 15 节，不是「图表集」

- 15 节是一条逻辑链，而不是一堆互不相干的图：阅读地图 → 四组基本事实 → 三要素被改写 → 六维作用力 → 产业规模 → 行业赋能 → 区域格局 → 全球格局 → 要素怎么流动 → 概念关系图谱 → 自己调参的模拟器 → 时间线 → 落地场景 → 结论 → 数据来源。
- 门户（第 00 节）是一面**阅读地图**：12 张卡片分别写明每一节讲什么，点一下直接跳过去。
- 顶栏 14 项导航随滚动自动高亮当前章节，另有一条阅读进度条。
- 每节共用同一副骨架（编号 + 一句话结论 + 引导语 + 图卡），图卡也都是同一套版式（标题 + 口径徽章 + 图形 + 图例 + 工具栏），读者不需要在每一节重新学一遍怎么看。

### 亮点二：16 张图全部手绘 SVG，而且每张都能「交出数据」

- 没有引入任何图表库：坐标轴、网格、渐变、气泡、流线、力导向、环形仪表全部自己算、自己画；唯一第三方件是本地内置的 5 个 d3 子模块（只服务于关系图谱）。
- 每张图都自带「图表 ⇄ 数据表」切换，数据表是真的 `<table>`（带表题与行/列头），读屏用户与要抄数的人都有出口。
- 每张图都能导出 **PNG / SVG / CSV** 三种格式，导出的是**同一份数据**（数据表与 CSV 由同一份规格生成，图和表不会各说各话）。
- 所有图都有悬停读数；20 张卡片各挂一枚**口径徽章**（公开统计 / 测算整理 / 含预测），规则是**保守取最弱一环**，口径写在图上而不是藏在文档里。
- 第 14 节可把 16 张图的表格 + 12 条来源**一次打包成一个 CSV**（按卡片分节），Excel 打开即可用。

### 亮点三：几处「硬图」都做了取舍

- **省级分级填色地图**（06）：34 个省级单元按**五档分位数**着色（线性分档会把大部分省份挤成一色），带**南海诸岛插图**与**前五名高亮**，两个指标可切换；边界几何在构建期抽稀到 28 KB，运行时零请求。
- **世界地图**（07）：陆地轮廓作安静底图，只给 18 个代表国家按分位数填色并标注国名（台湾已并入中国，并叠加南海九段线），算力与企业数两个指标可切换。
- **热力矩阵**（05）：15 个行业 × 5 项指标，同一行里单位完全不同（渗透率 %、市场规模亿元、人才指数 /100），所以**只在列内比深浅**；整格用科学可视化的经典 jet 彩虹色阶，格子里照实写**原始数值**。
- **小倍数图**（05）：三块小图**共用同一套纵轴刻度**，谁涨得快直接比高度；年份刻度只标在最下面一格，产业身份交给标题前的色点。
- **敏感性分析**（10）：龙卷风图回答「先调哪个」，蒙特卡洛 500 次抽样（固定种子）回答「结果有多不确定」。
- **要素流向图**（08）与**关系图谱**（09）：21 个节点、36 条关系的全景；点/拖节点、滚轮缩放、空白平移、悬停高亮邻接、双击释放、「适应窗口」一键复位。

### 亮点四：一台能自己调参的生产力模拟器

- 四个旋钮（AI 渗透率 / 数据要素投入 / 数字人才密度 / 研发强度）→ 实时算出五项输出，外加一个**综合新质生产力指数**（环形仪表）。
- 三套预设（当前基线 / 制造强国 / 全面智能化）+ 一键复位；调完旋钮，下面两张敏感性图**立刻重算**（90ms 防抖），不需要点「计算」。
- 页面明确标注这是**公开的线性示意模型，不是预测**，公式就写在卡片下方。

### 亮点五：中英双语 + 亮暗双主题，都不是「复制两份」

- 英文不是另做一套页面，而是多一张 **119 键**的中英文案表 + 同一份渲染逻辑；图表内所有文字（轴标题、图例、气泡名、单位）都走同一个取值函数。
- 切语言时**不重置**你已经调好的模拟器参数、选中的行业、正在看的年份。
- 配色全部来自一份设计令牌（`tokens.css`），切换亮/暗时整站重绘，导出的 PNG / SVG 也不掉色（图形用表现属性着色，不依赖外部样式类）。

### 亮点六：无障碍、响应式与「可分享的地址栏」

- **68 组**前景/背景配色在亮暗两档各测一遍（WCAG 2.1），门槛分三档（正文 ≥ 4.5:1、大字与图形 ≥ 3:1、数据填充 ≥ 1.9:1）。
- **11 档视口**（360 → 1440px）逐档真机体检：零横向溢出、触控目标 ≥ 44px、锚点跳转不被吸顶栏遮挡、无网格孤儿行。
- 时间线整条只占**一个 Tab 停点**，进去后方向键逐个浏览、`Home` / `End` 跳首尾、`Esc` 退出，并播报「第 i / n 个节点：年份 · 类型 · 标题」。
- 图表容器有可及名（`role="img"` + 说明）并各配一份「数据表」等价物；禁用脚本时 `<noscript>` 面板仍给出四个核心数字。
- 「复制当前视图链接」把语言 / 主题 / 行业 / 年份 / 地图指标 / 四个旋钮都编码进地址栏，对方打开**首帧就是同一屏**。

### 亮点七：数据链路与 2964 条自检断言 —— 数字不靠人记

- **数据与呈现分离**：48 个 CSV 数据集（306 行、带类型化表头、可 `git diff`、Excel 能直接打开）→ `node data/build.mjs` → 页面加载的 `data.js`；`--check` 会逐字节比对「仓库里的 `data.js` 就是这些 CSV 生成的结果」，手改产物当场失败。
- **8 个自检脚本、2964 条断言**（静态 2787 + 真机 177）：结构一致性、站内跳转、中英对齐、对比度与 ARIA、体积预算与零联网、数据链路、11 档布局体检、166 条交互冒烟（工具栏 / 跨图联动 / 导出 / 分享链接 / 双语 / 口径徽章双向核对 / 时间线键盘路径）。
- 这些脚本还**反向查自己**：文档里的数字（README 复杂度清单、HIGHLIGHTS、FEATURES）由脚本核对，对不上就报「文档过期」。
- CI 已挂上：改动 `vis2/` 自动跑静态自检，真机自检每晚跑一次、也可手动触发。

### 亮点八：零联网、零依赖、体积可控

- 全站 **19 个文件 / 磁盘 678 KB / gzip 后 327 KB**（其中 160 KB 是首屏那张背景图），任何静态托管都能发布。
- 没有任何 `fetch` / `XMLHttpRequest` / 动态 `import` / `@import` / 外链资源，也没有 `type="module"`：**双击 `index.html` 就完整可用**。
- **9 条 gzip 预算**写死在脚本里，任何一项超线都会失败，并写明「为什么设这个数」，逼着改动者要么瘦身、要么在预算里写下理由再上调。
