## 二、评测视角：它和"一份常见的数据可视化作业"差别在哪

| 维度 | 常见做法 | 本作业的做法 | 怎么验证 |
|---|---|---|---|
| **数据** | 数字手写进 JS 里 | CSV 是唯一数据源，`data.js` 是**构建产物**（文件顶部写着"请勿手改"） | `node data/build.mjs --check`（逐字节比对，不一致直接失败） |
| **图表** | 引一个图表库 | 14 个引擎**全部手写 SVG**：坐标轴、网格、渐变、气泡、流线、力导向、仪表都是自己算的 | 打开页面；源码见 `charts.js`（2441 行 / 14 个 `charts(container, cfg)` 引擎） |
| **图与表的关系** | 图是组件，数是另一份，容易"图改了表没改" | 每次渲染**同时**交出图形与一份 `tableSpec`（caption + 列名 + 取行函数）；"数据表"视图与"导出 CSV"**都由这一份规格生成** | 任一卡片切换「数据表」⇄「导出 CSV」，两处数字与图上的点必然一致 |
| **双语** | 另做一套英文页面（两份要同步维护） | 一份渲染逻辑 + 一张 114 键文案表，图表内所有文字走同一个取值函数 | 切 EN 后图表内所有轴标题 / 图例 / 气泡名都变英文（`parity-check.mjs` 1491 条断言守着） |
| **口径说明** | 写在文档里 | 17 张卡片各挂一枚**口径徽章**（公开统计 / 测算整理 / 含预测），规则是**保守取最弱一环** | 页面每张卡片标题右侧；`smoke.mjs` 把徽章与数据登记表**双向核对** |
| **质量** | 人肉点一遍 | 8 个脚本 / 2696 条断言，且**反向查自己**：数据、注释、文档里的数字全被断言 | `node selfcheck.mjs --full` |
| **可交付性** | 要起服务器、装依赖 | 双击即用；断网可用；`budget-check.mjs` 守住"零联网"承诺（禁 `fetch` / `XHR` / 外链资源 / `type="module"`） | 断网双击 `index.html` |

> 一句话概括差别：**这份作业把"数据 → 图 → 表 → 导出 → 文档"串成了一条可自动验证的链路**，
> 而不是交一组截图。

## 三、七条关键亮点

### 亮点 ① 一条主线，而不是一个"图集"

章节之间是有逻辑的，不是 14 张图随便排：

```text
00 阅读地图 → 01 先看四个数字 → 02 三要素怎么被改写 → 03 六维作用力
   → 04 产业规模 → 05 行业赋能 → 06 区域格局 → 07 全球格局
   → 08 要素怎么流动 → 09 概念关系图谱 → 10 自己调参的模拟器
   → 11 七十年时间线 → 12 八个落地场景 → 13 数据来源与口径
```

- 首屏是**阅读地图**：11 张卡片写明每一节讲什么，点一下直接跳过去；
- 顶栏 **13 项导航**随滚动高亮当前章节，另有一条阅读进度条；
- 每张图卡片下面直接写着**口径说明与数据来源**，读者不需要翻文档。

### 亮点 ② 13 张图全部手绘，而且每张图都"交得出数据"

没有图表库。更重要的是每张图同时提供四种出口：

| 出口 | 说明 |
|---|---|
| 图形 | 手写 SVG，用**表现属性**着色（不是 CSS 类）—— 换主题只需重画一次，导出 PNG/SVG 也不会"掉色" |
| 数据表 | 一键切换成带 `caption`、行列表头的真 `<table>`，读屏用户与要抄数的人都有出口 |
| 导出 | 每张图 **PNG / SVG / CSV** 三种格式，导出的是**同一份数据** |
| 无障碍名 | 容器挂 `role="img"` + 图题 `aria-label`，内部画布标 `aria-hidden`（可及名只播报一次，不会重复念"无名图片"） |

- 页面共 **19 个 SVG**（13 张图 + 模拟器内 6 个环形仪表）；
- `smoke.mjs` 会逐个断言工具栏、按钮、数据表行数、**CSV 表头**与**导出文件名**，
  所以"图改了、表没改"这类问题在提交前就会被抓到。

### 亮点 ③ 四张"硬图"，每一张都有明确的取舍

| 图 | 难在哪 | 怎么解决 |
|---|---|---|
| **省级分级填色地图**（06 节） | 省域差异极大：北京 3900 家 AI 企业 vs 西藏 15 家，线性分档会把 25 个省挤成一色 | 用**五档分位数**着色；边界几何在**构建期**抽稀到 28 KB（运行时零请求）；含**南海诸岛插图**；两个指标可切换、前五名可高亮 |
| **热力矩阵**（05 节） | 同一行里是渗透率 %、市场规模亿元、人才指数 /100，单位完全不同，深浅没法跨列比 | **列内归一化**（只在一列里比深浅）；格子里照实写**原始数值**，数据表与导出 CSV 也是原始值 |
| **小倍数图**（05 节） | 想比"谁涨得更快"，三块小图必须说同一种"高度语言" | 三格**共用同一套纵轴刻度**；宽屏三列、窄屏竖排；2024 年端点与上面的产业条形图**逐值一致**（由 `check.mjs` 断言，不靠肉眼） |
| **敏感性分析**（10 节） | 读者其实问两个不同的问题：先调哪个？结果有多确定？ | **龙卷风图**（一次只动一个因素，0→100）回答前者；**蒙特卡洛 500 次抽样**（±15% 扰动）回答后者；两张图共用同一个 `model()`，随机数用**固定种子**，换语言 / 换主题不会乱跳 |

### 亮点 ④ 交互不只是"悬停显示数值"，而是能回答"如果呢"

| 交互 | 做了什么 |
|---|---|
| **年份播放器** | 同时驱动折线图焦点与小倍数图的高亮列；两图数据对齐由 `check.mjs` 断言 |
| **跨图联动** | 点气泡矩阵里的行业，下面的产业条形图与落地场景一起响应（含"该行业暂无场景"的空集兜底） |
| **生产力模拟器** | 四个旋钮（渗透率 / 数据要素 / 人才密度 / 研发强度）→ 五项输出 + 综合指数；三套预设 + 一键复位；拖动时下面**两张敏感性图实时重算**（90ms 防抖，不点"计算"） |
| **分享链接** | 选中的年份 / 行业 / 地图指标 / 四个旋钮都编码在地址栏；首屏一颗「复制当前视图链接」，对方打开**首帧就是同一屏**（不用等脚本跑一遍） |
| **可带走** | 第 13 节提供「打包下载全部数据（CSV）」：13 张图的表格 + 12 条来源合成一个文件，Excel 直接打开 |
| **键盘可达** | 时间线整条只占**一个 Tab 停点**，进去后用方向键逐个浏览、`Home/End` 跳首尾、`Esc` 收起，并在页面上写明这条键盘路径 |

### 亮点 ⑤ 双语与双主题：是"一份逻辑"，不是"两套页面"

- **英文不是另做一套页面**：多一张 114 键的文案表；图表内的轴标题、图例、气泡名、单位都走同一个取值函数；
- 切语言**不重置**你已经调好的模拟器参数、选中的行业、正在看的年份；
- 英文模式下**零中文残留**，连 `aria-label` 与单位括号都跟着变（中文「（%）」→ 英文「 (%)」）；
  这条规则抓出过一个肉眼完全看不出来的漏洞：切到英文后读屏仍在念中文的 `aria-label`；
- 亮暗主题的配色全部来自一份设计令牌 `tokens.css`，切换时图表按新色值重绘，导出与截图都不掉色；
- **对比度是算出来的**：60 组前景/背景配色逐组做 WCAG 2.1 实测（亮暗两档），并且
  `tokens.css` 注释里写的比值也要和实测算出来的一致。这一轮体检抓到并修掉 5 个真问题，例如
  亮色主题的说明文字 **2.99:1**（小字要 4.5:1）→ 压深到 **5.15:1**，键盘焦点环 **1.13:1** → **3.19:1**。

### 亮点 ⑥ 质量是脚本"量"出来的，而且脚本会反向查自己

| 脚本 | 类型 | 断言 | 管什么 |
|---|---|---|---|
| `check.mjs` | 静态 | 569 | 结构一致性：词表键、挂载点、选择器、数据形状、脚本顺序 |
| `link-check.mjs` | 静态 | 47 | 锚点 / 脚本生成跳转 / 资源引用，空链接与外链 `rel` |
| `parity-check.mjs` | 静态 | 1491 | 中英对齐 8 条规则（含"中文里的数字必须出现在英文里"） |
| `a11y-check.mjs` | 静态 | 217 | 60 组对比度 + ARIA 引用 + 可及名 + 结构 + 焦点 |
| `budget-check.mjs` | 静态 | 168 | 8 条 gzip 预算、请求数、零联网承诺、文档数字不许过期 |
| `data/build.mjs --check` | 静态 | 41 | `data.js` 与 41 个 CSV 生成结果**逐字节一致** |
| `audit.mjs` | 真机 | 11 | 11 档视口（360→1440px）布局体检：溢出、裁切、触控目标、锚点被吸顶栏遮挡 |
| `smoke.mjs` | 真机 | 152 | 工具栏 / 联动 / 播放器 / 三种导出 / 分享链接 / 打包 CSV / 口径徽章 / 键盘路径 / 双语 |

**三条"反向查自己"的规则**（这类错误肉眼几乎发现不了）：

1. `data.js` 必须与 `data/*.csv` 生成的结果**逐字节一致** —— 手改产物会当场失败；
2. 中文文案里的**数字必须出现在英文里** ——「12 个国家」翻成「Economies」会被抓出来；
3. **文档里的数字不许过期** —— README「复杂度清单」、本组文档里的同一批数字由脚本核对，
   改了一处忘了另一处就是失败。

一条命令：`node selfcheck.mjs --full`（静态 2533 条 + 真机 163 条 = **2696 条，0 失败**）。
CI 挂在 `.github/workflows/selfcheck.yml`：静态检查**每次提交**都跑，真机检查**每晚**跑一次。

### 亮点 ⑦ 零依赖、零联网：可交付性强，评审成本低

- 页面**一次网络请求都不发**：连省级地图边界都是构建期抽稀好的静态文件（28 KB）；
- 没有 `npm`、没有打包器、没有 `type="module"` —— 所以直接 `file://` 双击打开也完整可用；
- 全站 17 个文件 / 磁盘 415 KB / **gzip 135 KB**，任何静态托管都能发布；
- 部署方式：同一个 GitHub 仓库在 Netlify 上发**两个站点**（`vis` / `vis2`），各自指定发布目录，`git push` 后约 10 秒生效。

## 五、诚实的边界（已知限制）

- **数据是示意口径**：产业规模、省级算力与企业数、行业渗透率等为公开资料整理 + 合理测算，
  页面与 README 均写明"不作严谨统计引用"；地图底图**不是审图号地图**，仅示意轮廓；
- **模拟器是线性示意模型**：四项投入 → 五项输出的权重是人为设定，用来演示"相对重要性"，不是经济预测；公式写在卡片下方；
- **最弱的一环**：15 个行业的「人才密度 / 五年增速」来自招聘平台与年报的整理值，已在数据字典标注口径；
- **没有引入测试框架**：8 个脚本就是测试，好处是零依赖、可读；代价是没有覆盖率报告；
- **不做 PWA / 离线缓存**：因为本身就是静态文件，`file://` 已经是离线；
- **GitHub Pages 目前不可用**：本仓库 Pages 自 2026-09-14 起未成功部署（实测 `/vis2/` 404），
  日常预览请用双击或 `python -m http.server`，排查结论见 [DEPLOY-NETLIFY.md](./DEPLOY-NETLIFY.md) §0.5。
