## 亮点一：一张页面讲完一条主线，不是「图集」

从「一句话定义」到「省级算力地图」，章节之间是有逻辑的：

> 先看四个数字 → 三要素怎么被改写 → 六维作用力 → 产业规模 → 行业赋能 → 区域格局 → 全球格局 → 要素怎么流动 → 概念关系图谱 → 自己调参的模拟器 → 七十年时间线 → 八个落地场景 → 数据来源

- 首页有**阅读地图**：11 张卡片写明每一节讲什么、点一下直接跳；
- 顶栏 13 项导航随滚动高亮当前章节 + 一条阅读进度条；
- 每个图表卡片下面都写着**口径说明与数据来源**，不需要去翻文档。

## 亮点二：13 张图全部手绘 SVG，而且每张图都给得出「数字」

没有引入任何图表库 —— 坐标轴、网格、渐变、气泡、流线、力导向、仪表盘都是自己算、自己画的。

更重要的是**每张图都能"交出数据"**：

| 能力 | 说明 |
|---|---|
| 图表 ⇄ 数据表 | 一键切换成带 `caption` 与行列表头的真 `<table>`，读屏与要抄数的人都有出口 |
| 导出 PNG / SVG / CSV | 13 张图各 3 种格式，导出的是**同一份数据**（表格视图与 CSV 表头同源生成） |
| 悬停读数 | 所有图都有数值提示，不靠颜色猜大小 |
| 跨图联动 | 点气泡矩阵里的行业，下面的产业条形图与落地场景会一起响应（含「该行业暂无场景」的兜底提示） |

## 亮点三：四张「硬图」，每一张都做了取舍

| 图 | 难在哪 | 怎么解决 |
|---|---|---|
| **省级分级填色地图** | 省域数值差异极大（北京 3900 家 vs 西藏 15 家），线性分档会把大部分省份挤成同一色 | 用**五档分位数**着色；边界几何在构建期抽稀到 28 KB；带**南海诸岛插图**与前五名高亮；两个指标可切换 |
| **热力矩阵** | 同一行里是渗透率 %、市场规模亿元、人才指数 /100，单位完全不同 | **列内归一化**（只在一个列里比深浅），格子里照实写原始数值，导出 CSV 也是原始值 |
| **小倍数图** | 想比「谁涨得更快」，就得让三块小图说同一种「高度语言」 | 三格**共用同一套纵轴刻度**，配色跨格一致，宽屏三列 / 窄屏竖排，年份刻度只标在最下面一格 |
| **敏感性分析** | 读者要问两个不同的问题：先调哪个？结果有多确定？ | **龙卷风图**（一次只动一个因素，0→100）回答前者；**蒙特卡洛 500 次抽样**（±15% 扰动）回答后者；两张图共用同一个公开模型，随机数用固定种子，换主题/换语言不会跳 |

## 亮点四：1 台能自己调参的生产力模拟器

四个旋钮（AI 渗透率 / 数据要素投入 / 数字人才密度 / 研发强度）→ 实时算出五项输出：
全要素生产率提升、GDP 拉动、运营成本下降、单位产出能耗下降、新增岗位，外加一个**综合新质生产力指数**（环形仪表）。

- 三套预设（当前基线 / 制造强国 / 全面智能化）+ 一键复位；
- 调完旋钮，**下面两张敏感性图立刻重算**（90ms 防抖），不需要点「计算」；
- 页面明确标注这是**公开的线性示意模型，不是预测** —— 公式写在卡片下方。

## 亮点五：中英双语和亮暗主题，都不是「复制两份」

- **逻辑只有一份**：英文不是另做一套页面，而是多一张 114 键的文案表；图表内所有文字（轴标题、气泡名、图例、轴单位）都走同一个取值函数；
- 切语言时**不重置**你调好的模拟器参数、选中的行业、正在看的年份；
- 英文模式下**零中文残留**（连 `aria-label` 与单位括号都跟着变：中文用全角「（%）」，英文用半角「 (%)」）；
- 亮暗主题：配色全部来自一份设计令牌，切换时图表按新色值重绘，导出/截图不掉色；
- **把「这一屏」发给别人**：你选中的年份、行业、地图指标、四个旋钮都编码在地址栏里，
  首屏「复制当前视图链接」按钮一按即可复制 —— 对方打开**首帧就是同一屏**（不用等你解释点了哪里）。

## 亮点六：能读、能用、能带走

- **无障碍**：跳转到正文、键盘可达、图表容器有可及名、切换按钮带 `aria-pressed`、状态变化用 `role="status"` 播报；
  时间线是唯一一个「图形自己可聚焦」的地方，整条**只占一个 Tab 停点**（方向键逐个浏览、`Home/End` 跳首尾、`Esc` 收起，
  并在容器上写明这条键盘路径）；17 张卡片各有一枚**口径徽章**（公开统计 / 测算整理 / 含预测，保守取最弱一环）；
  60 组前景/背景配色做过 WCAG 对比度实测（红/绿/灰全部达标），并尊重系统的「减少动态效果」；
- **响应式**：11 档宽度（360 → 1440px）实测零横向溢出，顶栏在窄屏收成抽屉；
- **能带走**：图表可导出 PNG/SVG/CSV（同一张图三种格式，数据一样），数据可整体下载（`data/*.csv`）；
  第 13 节还提供**「打包下载全部数据（CSV）」** —— 13 张图的表格 + 12 条来源合成一个文件，Excel 直接打开、不用逐个点；
  打印样式也是调过的。

## 亮点七：零联网、零依赖，双击就能看

- 页面**一次网络请求都不发**：连省级地图边界都是构建期抽稀好的静态文件；
- 没有 `npm`、没有打包器、没有 `type="module"` —— 所以直接 `file://` 双击打开也完整可用（语言、主题、导出、模拟器全都能用）；
- 全站 17 个文件、磁盘 415 KB、**gzip 后 135 KB**，任何静态托管都能发布。

## 亮点八：质量是脚本"量"出来的，不是感觉出来的

| 自检脚本 | 数量 |
|---|---|
| 静态自检 6 个（结构 / 跳转 / 中英对齐 / 无障碍与对比度 / 体积预算 / 数据链路） | **2533 条断言** |
| 真机自检 2 个（11 档视口布局体检 + 交互冒烟） | **163 条断言**（152 条交互 + 11 档视口） |

一条命令：`node selfcheck.mjs`（加 `--full` 连真机一起跑）。
CI 里挂在 `.github/workflows/selfcheck.yml`：静态检查每次提交都跑，真机检查每晚跑一次。
其中不少规则是**反向查自己**的，例如：

- `data.js` 必须与 `data/*.csv` 生成的结果逐字节一致（手改数据文件会被拦下）；
- 中文文案里的**数字必须出现在英文里**（「12 个国家」翻成「Economies」会被抓出来）；
- `tokens.css` 注释里写着的对比度比值，必须与实测算出来的一致；
- README 里「复杂度清单」的数字必须与实测一致（**文档会过期，脚本不许它过期**）。
