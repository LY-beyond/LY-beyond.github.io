## 亮点 ① 数据链路：CSV 是唯一数据源，`data.js` 是产物

大多数「静态可视化作业」的数据是手写进 JS 里的；这里把它当成一条正经的数据管线来做：

```text
data/*.csv        40 个数据集（类型化表头 列名:text|number|boolean|json，UTF-8 带 BOM，Excel 能开）
data/sim-model.js 模拟器模型函数（函数进不了 CSV，构建时原样内联）
        │  node data/build.mjs
        ▼
data.js           页面加载的数据模块（顶部写着「请勿手改」）
        ▲  node data/build.mjs --extract  ← 把手改同步回 CSV
```

**为什么值得这么做**

- **可 diff**：CSV 一行一个记录，`git diff` 能看清「哪个省、哪一年、哪个数」被改了，
  而不是在一坨 60 KB 的 JS 对象里找差异；
- **不许漂移**：`node data/build.mjs --check` 断言「仓库里的 `data.js` 就是这些 CSV 生成的结果」（逐字节比较），
  手改产物会立刻失败 —— `selfcheck.mjs` 已包含这一步；
- **不许丢数据**：`--extract` 会把 `AI_DATA` 的每个叶子与数据集清单对账，
  「有数据没进 CSV」直接报错（这次重构就是靠它确认 451 条双语文案一条没少）；
- **重构有保险绳**：`--verify <另一个 data.js>` 逐字段比对两份数据，连 `sim.model` 也放在 3 组输入下比较输出；
- **文档跟着数据走**：`--docs` 从表头 + 类型 + 每个数据集的中文说明生成[数据字典](data/README.md)，
  说明写在 `manifest.json` 的 `note` 里，重新抽取时会被保留。

**两个容易踩的坑，都写进了构建器**

1. **类型化表头**：`110000`（行政区划代码）必须是 `text`，否则往返一趟会变成数字，
   与地图几何里的字符串 id 对不上 —— 地图会整片不填色；
2. **空单元格 ≠ 空字符串**：非文本列留空表示「这一行没有这个字段」（`data.js` 里该键不出现），
   与 `false` / `0` 严格区分 —— 「2025 年是预测」正是靠这个布尔列表达的。

**切表规则**（`--extract` 自动执行，不靠人配）：容器里「元素是对象的数组（≥2 项）」

## 亮点 ② 13 张图全部手绘 SVG：一份数据，三种出口

没有引入图表库。`charts.js`（2356 行）里有 14 个引擎函数，每个都以 `charts(container, cfg)` 的形式被 `app.js` 调用：

| 引擎 | 用在哪 | 引擎 | 用在哪 |
|---|---|---|---|
| `radar` | 六维雷达（传统 vs AI 赋能双系列） | `choropleth` | 省级分级填色地图（五档分位） |
| `lineArea` | 产业规模双曲线（预测段虚线） | `heatmap` | 15 行业 × 5 指标热力矩阵（列内归一化） |
| `dualBars` | 三次产业双组条形 | `smallMultiples` | 三次产业七年轨迹（共享纵轴） |
| `hRankBars` | 12 经济体横向排名 | `tornado` | 单因素敏感性 |
| `bubble` | 15 行业气泡矩阵（可点选联动） | `monteCarlo` | 500 次抽样的分布直方图 |
| `flowChart` | 要素重构流向（悬停只留相关流线） | `timelineRail` | 七十年时间轴 |
| `forceGraph` | 21 节点 / 36 边可拖动力导向图 | `gauge` | 模拟器的 6 个环形仪表 |

**每个引擎都必须同时交出三样东西**，这是 `app.js` 里 `chartTools()` 定下的契约：

1. **图形**：SVG 用**表现属性**着色（不是 CSS 类）—— 这样切换主题只要重画一次即可自动换色，
   导出 PNG/SVG 也不会「掉色」（CSS 类在导出的独立 SVG 里可能找不到样式）；
2. **数据表**：每次渲染同时交出一份 `tableSpec()`（`caption` + 列名 + 取行函数），
   「数据表」视图与「导出 CSV」**都从这一份规格生成** —— 图和表永远是同一份数据，
   不会出现「图改了、表没改」的经典事故（`smoke.mjs` 会断言 CSV 表头与导出文件名）；
3. **无障碍名**：容器挂 `role="img"` + 图题 `aria-label`，内部 SVG 画布标 `aria-hidden`
   （可及名只播报一次，不会重复报「无名图片」）。

**卡片上还有第四样东西：口径徽章**（`cardHead(name, caption, provKey)` 的第三个参数）。

「这批数据有多硬」不该只写在文档里 —— 17 张卡片各挂一枚徽章，取值 `sourced`（公开统计）/ `modeled`（测算整理）/
`projected`（含预测），规则是**保守取最弱一环**：一组数据里只要含预测年份，整组就标「含预测」。
口径存在 `data/manifest.json` 的 `provenance` 里（是数据，不是文案），构建成 `AI_DATA.provenance`；
`app.js` 的 `provBadge()` **没登记就什么都不加**（宁可少一枚徽章，也不替数据编一个口径），
`check.mjs` 静态拦「引用了没登记的键 / 某张卡漏挂」，`smoke.mjs` 在浏览器里把 17 枚徽章与登记表**双向核对**
（少了说明漏挂，多了说明有卡片没登记）。

**尺寸与字体的一件事**：所有图表用 `viewBox` 但画布宽度跟随**容器实际宽度**（上限 = 设计宽度 900/960/700），
所以字号在任何屏幕上都是 11–13px（1:1）；如果只写 `width:100%` + `viewBox`，宽屏会把 24px 的标题放大到 46px、
手机又把 12px 压到 3.5px。容器宽度变化 ≥24px 才节流重画一次（`audit.mjs` 会量出「12 单位标签实际剩几 px」）。

## 亮点 ③ 四张「硬图」的设计取舍

### 分级填色地图（B1）

- **为什么用分位数**：北京 3900 家 AI 企业、西藏 15 家，线性分档会让 25 个省挤进同一档；
  五档分位让「头部、腰部、尾部」都看得见；
- **几何是构建期产物**：原始省级边界约 570 KB / 1.9 万点 → 等距圆柱投影（35°N 做 cos 校正）
  → Douglas–Peucker 抽稀 → 量化 → **28 KB**（每点约 1.81 B）；运行时零网络请求；
- **抽稀的两个坑**：小政区会被抽没（澳门！），所以按面积自适应容差；抽完必须检查 `NaN`（`check.mjs` 会拦）；
- 右下角是**南海诸岛插图**（70 个点 + 9 条线），这是中国地图的常规画法；
- 底图**不是审图号地图**，页面与 README 都写明「示意轮廓，不作行政区划依据」。

### 热力矩阵（B2）

列内归一化：渗透率是 %、市场规模是亿元、人才指数是 /100，只有**同一列内**比深浅才有意义。
格子里照实写原始数值，导出的 CSV/数据表也是原始值（不是 0–1 的着色值）。

### 小倍数图（B3）

三格**共享同一套纵轴刻度**（这是小倍数图的全部意义），谁涨得快直接比高度；
宽屏三列、窄屏竖排，年份刻度只标在最下面一格；产业身份交给标题前的色点，不靠颜色记顺序。
2024 年的两个端点与上面的三次产业条形图**逐值一致**，由 `check.mjs` 断言（页面上写着这条承诺）。

### 敏感性分析（B4）

- **龙卷风图**：固定其他三项，把一项从 0 扫到 100，条形长度 = 指数能被拉开的区间 → 回答「先调哪个」；
- **蒙特卡洛**：四项在 ±15% 内同时扰动、抽 500 次，虚线标 P5 / 中位数 / P95 → 回答「有多不确定」；
- **两张图共用同一个 `model()`**（`data/sim-model.js`，模拟器、龙卷风、蒙特卡洛三处调用），
  所以「旋钮位置 → 结果」在图与数之间永远一致；
- **随机数用固定种子的 mulberry32**：换语言 / 换主题会整页重绘，如果每次都重新随机，
  同一组参数下的分布图会莫名其妙地跳；固定种子让它可复现；
- 拖动滑块时重算走 90ms 防抖，避免每一帧都重算 500 次抽样。

> 一个小细节：`charts.js` 自己不去读词表，但它在 `<script>` 顺序里排在 `i18n.js` 之后，
> 于是用一个 4 行的 `tk(key, fallback)` 兜底（缺词表时回退**英文**而不是中文）——
> 「力导向引擎未加载」这类错误提示在英文界面下不会冒出中文。

## 亮点 ④ 中英双语：一份引擎 + 一张文案表

```text
        中英共用                     仅英文
   ┌──────────────────┐        ┌────────────────────────┐
   │ app.js（渲染逻辑） │        │ i18n.js 的 en 表        │
   │ charts.js（绘图）  │ ◄────  │ 114 键（与 zh 表逐键对齐）│
   └────────┬─────────┘        └────────────────────────┘
            │ 读 { zh, en } / T('key')
   ┌────────▼─────────┐
   │ data/*.csv → data.js │  451 条双语文案（两侧非空、英文无中文）
   └──────────────────┘
```

`parity-check.mjs` 把「翻译不同步」变成可自动判定的规则（1491 条断言）：

| 规则 | 为什么 |
|---|---|
| zh / en 两表**键完全一致** | 少一个键，切到英文就会露出裸 key |
| 英文里**不许残留中日韩字符** | 中英混排是肉眼最不容易发现的漏翻 |
| **占位符集合一致** | `{n}` / `{name}` 少一个，插值就变成 `undefined` |
| **数字同步**：中文里的每个数字都要出现在英文里 | 「12 个国家」翻成「Economies」这种丢数字的错，肉眼极难发现 |
| 中英**相同时**必须是不含小写字母的字面量 | `%` / `ELFLOPS` / `P5` 可以相同，句子相同就是漏翻 |
| `index.html` 里有中文文本的元素**必须**有 `data-i18n` | 否则那块文案永远不变 |
| 含中文的 `aria-label` / `title` 必须有 `data-i18n-attr` | **这类漏洞肉眼完全看不出来**：切英文后读屏仍在念中文（本项目就是被这条抓出来的） |
| `app.js` / `charts.js` 里**不许有裸中文**（行内 `{ zh, en }` 与按语言分支的排版字面量除外） | 保证界面文案全部可翻译 |

单位括号也随语言变：中文「AI 渗透率（%）」、英文「AI penetration (%)」——
由 `app.js` 的 `withUnit()` 统一处理，并且这是唯一允许出现「按语言分支字面量」的地方
（`parity-check.mjs` 用「同一行是否读 `I18N.lang`」来识别这个豁免）。

「键数 ≥ 5 的嵌套对象」会切到自己的 CSV；更小的数组作为父行的一个 `json` 单元，
避免碎成几十个两行的文件。40 个数据集的划分就是这么来的。

## 亮点 ⑤ 无障碍：不是"加了几个 aria"，而是量出来的

`a11y-check.mjs`（静态）与 `smoke.mjs`（真机）分工：前者守代码里写了什么，后者守运行时到底对不对。

**对比度是算出来的**（WCAG 2.1 相对亮度公式，亮暗两档各 30 组）：

- 解析 `tokens.css` 成「亮 / 暗」两张令牌表，支持 `#hex` / `var()` / `color-mix(in srgb, …)`；
- **`color-mix` 必须按预乘 alpha 语义算**：`color-mix(in srgb, var(--c-primary) 72%, transparent)`
  得到的是 `rgba(15,118,110,.72)`，不是「掺 28% 白」——第一版算错了，焦点环的比值偏小；
- 门槛分三档：正文与说明文字 ≥ 4.5:1、大字与图形元素 ≥ 3:1、数据填充 ≥ 1.9:1
  （图表里的颜色不是唯一信息通道：每个值都有标签、悬停读数与数据表，按 1.4.11 的替代方案条款只需「能看出填充边界」）；
- **注释也被断言**：`tokens.css` 里 `--s-base` 后写着「（2.09:1 / 6.28:1）」，脚本会实测这两组并比对 ——
  写注释的人会漏改，脚本不会。

**这次体检抓出并修掉的 5 个真问题**（都是肉眼很难发现的）：

| 问题 | 实测 | 改法 |
|---|---|---|
| 亮色主题「说明文字」`--c-muted #8a97a0` 压在卡片上 | **2.99:1**（小字要 4.5:1） | 压深到 `#626f7b` → **5.15:1** |
| 同上，压在次级面板（对比表头）上 | **2.68:1** | 同上 → **5.44:1** |
| 暗色主题 `--c-muted #74838d` | 卡片 4.28:1 / 面板 3.89:1 | 提亮到 `#7f8f9a` → **5.02 / 4.56:1** |
| 11px 的强调色徽章（橙字压浅橙底） | **3.35:1** | 新增 `--c-accent-ink`（`color-mix` 压深）→ **4.6:1+** |
| 键盘焦点环 `--c-focus`（主色 30%） | **1.13:1**（WCAG 3:1） | 提到 72% → **3.19:1**；并让 `theme.css` 不再自己写 55% 的环 |

顺带把三级文字的层次重新拉开（正文 14.7 : 次级 7.5 : 说明 5.2），三档全部达标。

**结构与 ARIA**（217 条断言）：

- id 唯一；`aria-labelledby` / `aria-describedby` / `aria-controls` / `for` 指向的 id 都存在；
- 每个 `button` / `a` 都有可及名（可以是静态 `aria-label`，也可以是 `data-i18n-attr` 在运行时写入的）；
- **每个图表容器**都在「`role="img"` + 图题 `aria-label`」配对表里，且都有 `chartTools()` 的数据表等价物；
- **内部 SVG 画布标 `aria-hidden`**：可及名由容器承载，画布再报一次就成了「无名图片」；
- 唯一 `<h1>`、标题层级不跳级、landmark 齐全、`skip-link` 是第一个可聚焦元素、`tabindex` 不为正、
  `aria-hidden` 子树里没有可聚焦元素、`role` 取值在白名单内（打错 role 等于没写）；
- 键盘等价物：气泡图能点，但也有 `<select>` 行业筛选；图谱的「适应窗口」按钮挂在画布**外面**
  （塞进 `role="img"` 里会被读屏当图片内容吞掉）；
- 状态播报：筛选联动、模拟器结果、地图前五名三处都是 `role="status"`。
- **时间线是唯一一个「图形自己可聚焦」的地方，而且只占一个 Tab 停点**：容器 `tabindex="0"`，
  `←/→` 移动焦点环（`.tl-focus`）、`Home/End` 跳首尾、`Esc` 与失焦都收起，
  每步用 `role="status"` 播报「第 i / n 个节点：年份 · 类型 · 标题」；容器用 `aria-describedby`
  指向一句操作提示（`timeline.keys`，中英各一份）—— 反面做法是给 10 个节点各挂一个 `tabindex`，
  那等于把 Tab 串再拉长 10 格，`a11y-check.mjs` 会反向断言 `charts.js` 里**不存在** `tabindex`。

**刻意不检查的三件事**（写在脚本里，免得以后被当成漏检）：
卡片描边与分隔线不设门槛（不是承载信息的控件边界）；渐变底不做自动判定（文字会跨越渐变两端，只能在改色时人工目视）；
运行时按钮文案与聚焦顺序交给真机断言。

## 亮点 ⑥ 工程化：8 个自检脚本，一条命令跑完

```bash
node selfcheck.mjs          # 6 个静态检查（毫秒级，不联网、不开浏览器）
node selfcheck.mjs --full   # 再跑 2 个真机检查（真实 Chrome + CDP，约 1–2 分钟）
```

| 脚本 | 类型 | 断言 | 管什么 |
|---|---|---|---|
| `check.mjs` | 静态 | 561 | 结构一致性：词表键、`data-i18n` 键、挂载点（32）、选择器（26 个容器 id）、数据形状（双语叶子 / 热力 15×5 / 小倍数 3×7 且 2024 端点一致 / 年份序列 2019–2025 且与小倍数逐年等长 / 地图 34 行 / 全球 12 行降序 / 图谱 21 节点 36 边端点存在 / 模拟器 4 滑块 3 预设齐键）、vendor 顺序、五个新引擎导出 |
| `link-check.mjs` | 静态 | 47 | 17 处锚点 + 11 处脚本生成跳转 + 16 个资源；空链接、`javascript:`、外链缺 `rel="noopener"`、临时文件残留 |

| `a11y-check.mjs` | 静态 | 217 | 60 组对比度（含注释核对）+ ARIA 引用 + 可及名 + 结构 + 焦点 | 
| `budget-check.mjs` | 静态 | 168 | 8 条 gzip 预算、请求数 ≤ 22、**零联网**（禁 `fetch`/`XHR`/动态 `import`/`@import`/外链资源）、无 `type="module"`、数据摊销（68 B/条、1.81 B/点），并核对 README「复杂度清单」与另外两份文档里同一批数字 |
| `data/build.mjs --check` | 静态 | 40 | `data.js` 与 40 个 CSV 生成结果逐字节一致 |

> 真机断言合计 **157 条** = `smoke.mjs` 146 + `audit.mjs` 11（每档视口一条）。

**两个让这套东西好维护的约定**：

1. 每个脚本末尾打印 `SUMMARY script=… checks=N failed=M`，`selfcheck.mjs` 只认这一行来汇总断言数
   （所以新增一个脚本，只要遵守这个格式就会自动进入统计）；
2. **失败一律非零退出**，可以直接挂 CI 或提交钩子。

## 亮点 ⑦ 体积与性能：预算写进脚本，`README` 的数字不许过期

```bash
node budget-check.mjs     # 8 条 gzip 预算 + 请求数 + 逐文件明细
```

| 文件 | 磁盘 | gzip | 备注 |
|---|---|---|---|
| `index.html` | 21.7 KB | 6.2 KB | 14 个章节的骨架 |
| `styles.css` | 37.0 KB | 9.4 KB | 布局与组件（含 11 档断点） |
| `charts.js` | 104.8 KB | 31.0 KB | 14 个引擎（最大单文件） |
| `app.js` | 81.6 KB | 26.1 KB | 渲染与交互调度 |
| `data.js` | 61.9 KB | 20.2 KB | **构建产物**：40 个数据集 |
| `map-china.js` | 28.3 KB | 9.7 KB | 抽稀后的省级几何（1.81 B/点） |
| `i18n.js` | 22.8 KB | 9.5 KB | 114×2 条词表 |
| 5 个 d3 子模块 | 30.2 KB | 11.0 KB | 只服务于力导向图 |
| **合计（页面请求 17 个文件）** | **407.1 KB** | **131.8 KB** | 17 个请求 |

- **数据摊销**：`data.js` 里 306 个数组元素 ≈ 68 B/条（gzip 后），也就是说「多一个行业」的成本大约是几十字节；
- **预算的作用**：任何一项超线都会失败，并在输出里写明「为什么设这个数」，
  逼着改动者要么瘦身、要么在 `BUDGET` 里写下理由再上调；
- **文档防漂移**：README「复杂度清单」的 8 个数字由 `budget-check.mjs` 核对、`静态断言` 由 `selfcheck.mjs` 核对、
  `真机断言` 在 `--full` 时核对 —— 数字过期会直接变成失败。

性能上的几个取舍：整页只有一个页面、没有路由；`resize` 节流 180ms 且宽度变化 < 24px 不重画；
模拟器重算 90ms 防抖 + 500 次抽样固定种子；卡片与图表都在 DOM 里一次装配（没有虚拟滚动，因为总量只有 19 个 SVG）。

## 亮点 ⑧ 部署与踩坑记录

| 话题 | 结论 |
|---|---|
| `file://` 双击可用 | 全站无 `type="module"`、无 `fetch(`、无 `@import`、无外链资源 —— `budget-check.mjs` 会守着这条承诺；`localStorage` 失败时语言/主题回落到默认值 |
| 本地预览 | 双击 / `python -m http.server 8099 --directory vis2` / Live Server —— 三种方式效果一致 |
| GitHub Pages | ⚠️ **本仓库 Pages 自 2026-09-14 起未成功部署**（实测 `/vis2/` 全 404），排查见 [DEPLOY-NETLIFY.md](./DEPLOY-NETLIFY.md) §0.5；不要把 Pages 当日常预览 |
| Netlify | 一个仓库两个站点（`vis` / `vis2`），根目录 `netlify.toml` 故意不写 `publish`，各自在 UI 里指定；无构建步骤，`git push` 后约 10 秒生效 |
| 部署目录里有什么 | 页面只请求 17 个文件；`data/`（数据源 + 构建器）与 8 个自检脚本、4 份文档都在目录里但**不参与页面加载**（总共 71 个文件 / 691 KB） |

## ⚠️ 已知限制与取舍

- **数据是示意口径**：产业规模、省级算力与企业数、行业渗透率等为公开资料整理 + 合理测算，
  不同机构口径不一致，页面与 `README` 都写明「不作严谨统计引用」；底图**不是审图号地图**；
- **模拟器是线性示意模型**：四项投入 → 五项输出的权重是人为设定，用来演示「相对重要性」，不是经济预测；
- **只服务机构/桌面为主的使用场景**：窄屏可用（11 档实测无溢出），但没有做 PWA / 离线缓存（因为本身就是静态文件）；
- **15 个行业的「人才密度 / 五年增速」两列**来自招聘平台与年报的整理值，属于**最弱的一环**，已在数据字典里标注口径；
- **没有引入测试框架**：8 个脚本就是测试，好处是零依赖、可读；代价是没有覆盖率报告（`README` 用断言数代替）。

## 🧭 想改点什么？三条最常见的路径

### 1. 只改数据（最常见）

```bash
# 打开 data/ 里对应的 CSV（Excel 或编辑器都行），改完：
cd vis2
node data/build.mjs      # CSV → data.js
node selfcheck.mjs       # 全绿再提交
```

> 数据→图表的对应关系见 [data/README.md](./data/README.md)：每个 CSV 都有「数据路径 / 形态 / 行×列 / 对应页面哪一节」。
> 忘了重新构建也没关系：`--check` 会拦住（`selfcheck.mjs` 已包含）。

### 2. 加一节或加一张图

1. `index.html`：加一个 `<section class="section" id="xxx">`（含 `section-num` / `section-title` / `section-lead`）
   与一个 `<div class="viz" id="chart-xxx">` + 两个 `data-mount="xxx-head|-foot"`；
2. `i18n.js`：补 `nav.xxx` 与 `sec.xxx.title|lead`（两张表都要，`parity-check.mjs` 会核对）；
3. `data/`：新增一个 CSV 或往现有 CSV 加列 → `node data/build.mjs`；若要新数据集，先 `--extract` 再补 `note`；
4. `charts.js`：写引擎（或复用现有引擎），导出到 `window.CHARTS`；
5. `app.js`：加 `renderXxx()`，写好 `cardHead/cardFoot` + `chartTools(host, { name:'xxx', table: ... })`，
   并把 `['chart-xxx', D.xxx.caption]` 加进「`role=img` + `aria-label`」配对表；
6. 阅读地图（`data/overview.csv`）与顶栏导航各加一条；
7. `node selfcheck.mjs` —— 忘了哪一步，`check.mjs` / `a11y-check.mjs` / `link-check.mjs` 会当场指出来。

### 3. 换配色 / 换字体

只改 `tokens.css`（唯一出处）。改完跑 `node a11y-check.mjs`：
它会重新算 60 组对比度、核对注释里写的比值，并告诉你哪个组合掉到了门槛以下。
图表会通过 `getComputedStyle` 自动读到新色值，不需要改 `charts.js`。

## 🔍 自检速查

```bash
node selfcheck.mjs              # 全部静态自检（6 个脚本 / 2524 条断言）
node selfcheck.mjs --full       # 再加真机自检（157 条：146 交互 + 11 档视口）
node check.mjs                  # 只跑结构一致性
node link-check.mjs             # 只查锚点与资源引用
node parity-check.mjs           # 只查中英对齐
node a11y-check.mjs             # 只查对比度与 ARIA（会打印 60 组比值）
node budget-check.mjs           # 只查体积预算（会打印逐文件 gzip 明细）
node data/build.mjs             # CSV → data.js
node data/build.mjs --check     # data.js 与 CSV 是否一致
node data/build.mjs --docs      # 重新生成数据字典
node data/build.mjs --verify X  # 与另一份 data.js 逐字段比对
node audit.mjs                  # 真机布局体检（加 --json / --shots 存档证据）
node smoke.mjs                  # 真机交互冒烟（146 项）
```

需要浏览器时（`audit.mjs` / `smoke.mjs`）会自动探测 Chrome / Edge / Chromium，
也可以用 `set CHROME=…`（Windows）或 `export CHROME=…` 指定；两者都用 `file://` 打开本地页面，
不需要起服务器（`SITE_URL=http://…` 可切到本地服务器模式）。

CI（`.github/workflows/selfcheck.yml`）里静态自检每次提交都跑，真机自检每晚跑一次；
容器 / 无沙箱环境给 `CHROME_FLAGS=--no-sandbox` 补浏览器参数，脚本本身不写死沙箱开关。
