# 人工智能 · 新质生产力｜网页亮点（作者自述）

> 我是这个页面的作者。下面按"我当初为什么这么做"的顺序讲五个方面 ——
> **结构怎么排、配色怎么定、内容怎么串成一条线、功能上多做在哪、图为什么好看**，再补上数据与质量这两条底子。
> 全站数据由 **41 个 CSV 构建而来**，质量由 **8 个自检脚本（静态 2533 + 真机 163 条断言）** 兜住：
> 文中每个数字都能用文末的命令重新测出来。
> 面向课程评阅人的版本见 [KEY-HIGHLIGHTS.md](./KEY-HIGHLIGHTS.md)，访客速览见 [FEATURES.md](./FEATURES.md)，
> 使用与维护见 [README.md](./README.md)。

## 一、结构布局：一页读到底，但每一步都知道自己在哪

- **我选择"一个页面"而不是多页或路由**：全篇是一条完整论证，翻页会把它切断。整页 14 节，00 是阅读地图，01–13 是内容。
- **首屏先给地图**：读者第一眼看到 14 个入口的卡片墙，先知道全篇有几段、每段讲什么，再往下走 —— 而不是一上来就被丢进第一张图。
- **顶栏 13 个导航项吸顶常驻**：滚动时随时可跳；锚点跳转带补偿偏移，标题不会被吸顶栏压住（`audit.mjs` 逐档实测这一点）。
- **每节共用同一副骨架**：编号 + 一句话结论 + 引导语，然后才是图卡；13 张图卡都用同一套 `cardHead / cardFoot`，读者不需要重新学版式。
- **卡片内部顺序固定**：标题与口径徽章 → 图形 → 图例与说明 → 工具栏（图⇄表、导出）。眼睛停在同一个位置，就能找到同一类信息。
- **布局是弹性而非碰运气**：11 档视口（360 → 1440px）逐一实测，无横向溢出、无网格孤儿行、触控目标 ≥ 44px。

## 二、配色选择：一处令牌、亮暗两套，比值靠算不靠眼

- **全站颜色只有一个出处**：`tokens.css` 里的命名令牌。换配色只改这一个文件，图表通过 `getComputedStyle` 自动读到新色值，`charts.js` 一行都不用动。
- **亮/暗不是简单反色，而是两套完整设计**：切换时图表按新色值整体重绘，导出的 PNG / SVG 也不掉色 —— 因为图形用**表现属性**着色，不依赖外部 CSS 类。
- **颜色是算出来的**：60 组前景/背景配色（亮暗两档各 30 组）逐组跑 WCAG 2.1 相对亮度公式，门槛分三档（正文 ≥ 4.5:1、大字与图形 ≥ 3:1、数据填充 ≥ 1.9:1）。这轮体检抓出并修掉 5 个真问题：亮色说明文字 **2.99:1** → **5.15:1**，键盘焦点环 **1.13:1** → **3.19:1**。
- **连注释也被断言**：`tokens.css` 里写在 `--s-base` 后面的比值（2.09:1 / 6.28:1）会被脚本实测比对 —— 写注释的人会漏改，脚本不会。
- **配色的分工很清楚**：顺序色阶用"主色的五个透明度档"而不是五个色相，深浅与数值同序；分类色只用来区分身份，不用来编码大小。

## 三、内容的连续性：上一节的结论，就是下一节的提问

- **14 节是一条逻辑链，不是图集**：00 阅读地图 → 01 四组基本事实 → 02 三要素被改写 → 03 六维作用力 → 04 产业规模 → 05 行业赋能 → 06 区域格局 → 07 全球格局 → 08 要素流动 → 09 概念图谱 → 10 自己调参 → 11 时间线 → 12 落地场景 → 13 关于（含打包下载）。
- **跨图联动**：年份播放器同时驱动产业规模折线图的焦点与小倍数图的高亮列；"两图逐年对齐"这条承诺写进了脚本 —— `check.mjs` 断言 2024 端点与三次产业条形图逐值一致、2019–2025 年份序列与小倍数图逐年等长。
- **同一份数据贯穿所有出口**：每个引擎渲染时同时交出图形与一份 `tableSpec`（表题 + 列名 + 取行函数），"数据表"视图与"导出 CSV"都由这一份规格生成 —— 图和表不可能各说各话，图上写着"数据可导出为 CSV"时是真的能导出。
- **口径写在图上，而不是藏在文档里**：17 张卡片各挂一枚徽章（公开统计 / 测算整理 / 含预测），规则是**保守取最弱一环**（一组数据里含预测年份，整组就标"含预测"）；`manifest.json` 里没登记的键不会凭空长出一枚徽章。
- **整条论证可以带走**：第 13 节把 13 张图的表格 + 12 条来源合成一个 CSV 打包下载，读者读完能把材料挪进自己的表格继续用。

## 四、功能的多样性：不只"能看"，还能查、能调、能分享、能带走

- **同一张图三种出口**：图表 ⇄ 数据表切换、PNG / SVG / CSV 导出，13 条工具栏规格一致、位置一致。
- **能互动**：15 个行业气泡可点选并联动下方热力矩阵；地图可切换指标、可开"前五名"高亮；力导向图谱可拖动 / 缩放 / 双击释放。
- **能自己调**：第 10 节是一台可调参的生产力模拟器 —— 四个旋钮、三套预设、一键复位，下面两张敏感性图实时重算：龙卷风图回答"先调哪个"，蒙特卡洛（固定种子、500 次抽样）回答"有多不确定"。
- **能分享**：右上角「复制当前视图链接」把语言 / 主题 / 行业 / 年份 / 模拟器参数写进地址栏，新标签打开首帧就是同一屏（`smoke.mjs` 同时核对首帧与 `hashchange` 两条还原路径）。
- **能只靠键盘走完关键路径**：时间线整条只占一个 Tab 停点，进去后方向键逐个浏览、`Home/End` 跳首尾、`Esc` 收起，并播报"第 i / n 个节点：年份 · 类型 · 标题"。
- **面向不同读者的入口同时存在**：阅读地图给第一次来的人，导航给回头查的人，数据表与打包 CSV 给要用数据的人，键盘路径给不用鼠标的人。

## 五、可视化美观：13 张图全部手画

- **我没有引图表库**：`charts.js`（2441 行）里有 14 个引擎函数，都以 `charts(container, cfg)` 的形式被调用 —— 坐标轴、网格、渐变、气泡、流线、力导向、环形仪表都是自己算的，所以样式与主题能真正统一。
- **字号在任何屏幕上都是 11–13px**：图表用 `viewBox`，但画布宽度跟随**容器实际宽度**（上限 = 设计宽度）。若只写 `width:100%` + `viewBox`，宽屏会把 24px 的标题放大到 46px、手机又把 12px 压到 3.5px。
- **该共享的轴一定共享**：小倍数图三格共用同一套纵轴刻度（这是小倍数图的全部意义），谁涨得快直接比高度；年份刻度只标在最下面一格，产业身份交给标题前的色点，不靠颜色记顺序。
- **热力矩阵按列归一化**：渗透率是 %、规模是亿元、人才指数是 /100，只有列内比深浅才有意义；格子里照实写原始数值，导出的 CSV 也是原始值而不是 0–1 的着色值。
- **两处刻意的地图细节**：省级分级填色用**五档分位**而非线性分档（北京 3900 家企业、西藏 15 家，线性分档会让 25 个省挤进同一档）；右下角保留**南海诸岛插图**（70 点 + 9 线），这是中国地图的常规画法；底图只作示意，不是审图号地图。
- **装饰是克制的**：不做投影 / 立体 / 动画噱头，视觉层次交给色阶、网格密度与留白；悬停只留相关信息（例如要素流向图只保留与当前节点相关的流线）。
- **一次装配、不闪不抖**：卡片与图表在 DOM 里一次装配（没有虚拟滚动，因为总量只有 19 个 SVG）；`resize` 节流 180ms 且宽度变化 < 24px 不重画。

## 六、数据与质量：把"可信"做成可执行的检查

- **CSV 是唯一数据源**：`data/*.csv`（类型化表头，Excel 能直接打开）→ `node data/build.mjs` → `data.js`（顶部写着"请勿手改"）。一行一条记录，`git diff` 能看清"哪个省、哪一年、哪个数"被改了。
- **不许漂移**：`node data/build.mjs --check` 逐字节比对"仓库里的 `data.js` 就是这些 CSV 生成的结果"，手改产物当场失败 —— `selfcheck.mjs` 已包含这一步。
- **口径与来源是数据，不是文案**：17 张卡片的徽章登记在 `data/manifest.json`；没登记就不加徽章（宁可少一枚，也不替数据编一个口径），`smoke.mjs` 在浏览器里把徽章与登记表双向核对。
- **中英双语是一份逻辑，而不是两套页面**：多一张 114 键的文案表，图表内所有文字（轴标题、图例、气泡名、单位）走同一个取值函数。`parity-check.mjs` 把「翻译不同步」变成可自动判定的规则（1491 条断言）—— 包括"中文里的每个数字都要出现在英文里"，以及"切英文后读屏仍在念中文的 `aria-label`"（后一条真的抓出过一个肉眼完全看不出来的漏洞）。
- **无障碍是量出来的**：`a11y-check.mjs` 守静态（60 组对比度 + ARIA 引用 + 可及名 + 结构 + 焦点），`smoke.mjs` 守运行时（筛选联动、模拟器结果、地图前五名三处都播报）；时间线是全页唯一"图形自己可聚焦"的地方，且只占一个 Tab 停点。

### 8 个脚本，一条命令跑完

```bash
node selfcheck.mjs          # 6 个静态检查（毫秒级，不联网、不开浏览器）
node selfcheck.mjs --full   # 再跑 2 个真机检查（真实 Chrome + CDP，约 1–2 分钟）
```

| 脚本 | 类型 | 断言 | 管什么 |
|---|---|---|---|
| `check.mjs` | 静态 | 569 | 结构一致性：词表键、挂载点、选择器、数据形状、vendor 顺序、引擎导出 |
| `link-check.mjs` | 静态 | 47 | 锚点 / 脚本生成跳转 / 资源引用，空链接、`javascript:`、外链缺 `rel="noopener"` |
| `parity-check.mjs` | 静态 | 1491 | 中英对齐 8 条规则，逐键 × 逐条 |
| `a11y-check.mjs` | 静态 | 217 | 对比度 60 组（含注释核对）+ ARIA 引用 + 可及名 + 结构 + 焦点 |
| `budget-check.mjs` | 静态 | 168 | gzip 预算、请求数、**零联网**（禁 `fetch` / `XHR` / 动态 `import` / `@import` / 外链资源）、无 `type="module"`、文档数字防漂移 |
| `data/build.mjs --check` | 静态 | 41 | `data.js` 与 41 个 CSV 生成结果逐字节一致 |
| `audit.mjs` | 真机 | 11 | 11 档视口（360→1440）布局体检：溢出、裁切、触控目标、锚点被吸顶栏遮挡 |
| `smoke.mjs` | 真机 | 152 | 工具栏 / 联动 / 播放器 / 三种导出 / 分享链接 / 打包 CSV / 口径徽章 / 键盘路径 / 双语 |

真机断言合计 **163 条** = `smoke.mjs` 152 + `audit.mjs` 11（每档视口一条）。

- **预算写在脚本里**（见文末速查第 3 条）：任何一项超线都会失败，并写明"为什么设这个数"，逼着改动者要么瘦身、要么在 `BUDGET` 里写下理由再上调。
- **数据摊销**：`data.js` 里 309 个数组元素 ≈ 68 B/条（gzip 后）—— 所以"多加一个行业"的成本大约是几十字节。
- **零联网可交付**：无 `type="module"`、无 `fetch(`、无外链资源，双击 `index.html` 就完整可用；部署上是一个仓库发两个站点（Netlify，各站点指定发布目录），`git push` 后约 10 秒生效。（本仓库 GitHub Pages 自 2026-09-14 起未能成功部署，实测 `/vis2/` 404，排查结论见 [DEPLOY-NETLIFY.md](./DEPLOY-NETLIFY.md) §0.5。）

## 已知限制（我清楚它们）

- **数据是示意口径**：产业规模、省级算力与企业数、行业渗透率等为公开资料整理 + 合理测算，页面与 README 都写明"不作严谨统计引用"；底图不是审图号地图。
- **模拟器是线性示意模型**：四项投入 → 五项输出的权重是人为设定，用来演示"相对重要性"，不是经济预测。
- **15 个行业的"人才密度 / 五年增速"是最弱的一环**：来自招聘平台与年报的整理值，已在数据字典里标注口径。
- **没有引入测试框架**：8 个脚本就是测试，好处是零依赖、可读；代价是没有覆盖率报告。
- **不做 PWA / 离线缓存**：因为本身就是静态文件，`file://` 已经是离线。
