5.1 盒模型

每个元素都是一个盒子，看懂它，才看得懂布局

在 CSS 眼里，页面上每一个元素都是一个矩形盒子。理解盒子由哪几层组成、各占多少空间，是学会布局的第一步。

📦 盒模型的四层结构

由内到外依次是：content（内容区）→ padding（内边距）→ border（边框）→ margin（外边距）。

  • content：文字、图片真正占据的区域，由 width / height 决定。
  • padding：内容与边框之间的留白，背景色会覆盖到它。
  • border：边框本身，也会占据实际空间。
  • margin：盒子与盒子之间的距离，背景色不覆盖，且相邻外边距可能合并。

两种 box-sizing

取值width 的含义实际占宽
content-box（默认）仅内容区width + padding + border
border-box（推荐）含 padding 与 border就是 width

⭐ 关键点：默认情况下 width: 200px 只算了内容区， 加上 padding: 20px 和 border: 2px 后，盒子实际宽 244px—— 这正是"设了宽度却还是被撑破"的常见原因。 所以几乎所有项目第一行都会写 box-sizing: border-box。 

/* 推荐做法：让宽高包含 padding 与 border */
* { box-sizing: border-box; }

.card {
  width: 240px;
  padding: 16px;        /* 内边距 */
  border: 2px solid #ccc; /* 边框 */
  margin: 10px;          /* 外边距 */
}

⭐ 关键点解释： box-sizing: border-box 让 width 直接代表盒子最终占据的宽度， padding 与 border 向"内"挤压内容，而不是向"外"撑开盒子。 这样多个元素并排时，宽度相加就等于总宽，计算简单且不会溢出。
常见坑：不同元素的 margin 在垂直方向会发生"外边距合并"， 两个 20px 的相邻外边距只会得到 20px，而不是 40px。

拖动滑块，观察紫色 content、黄色 padding、实线 border 与虚线 margin 的变化。

5.2 文档流

元素默认是怎么一个个排上去的？

正常流（Normal Flow）是浏览器默认的排版方式。如果不写任何布局代码，元素就按正常流排列——它是一切布局的"基准状态"。

🌊 正常流的两条规则

块级元素（block）：从上到下依次排列，每个独占一整行，宽度默认撑满父容器。
行内元素（inline）：从左到右并排，一行放不下才换行，宽高由内容决定。

  • 常见的块级元素：div、p、h1、section、li
  • 常见的行内元素：span、a、strong、em、code
  • 行内块 inline-block：像行内元素一样并排，但可以设置宽高——两全其美。

⭐ 关键点：脱离文档流是指元素不再占据原来的位置。 position: absolute / fixed 和 float 都会让元素脱离正常流， 后面的元素会"补位"上来——这也正是"布局错乱"的常见来源。 第 8 章会专门讲定位。 

/* 块级：独占一行 */
div { display: block; }

/* 行内：并排，宽高由内容决定，设置 width 无效 */
span { display: inline; }

/* 行内块：并排，且可以设置宽高 */
.tag {
  display: inline-block;
  width: 80px;
  height: 32px;
}

⭐ 关键点解释：行内元素设置 width / height 不会生效， 因为它的尺寸由内容撑开，这是初学者最常踩的坑之一。 需要"能并排又能设尺寸"时改用 inline-block。
注意：inline-block 之间的换行符会渲染成一个空格间隙， 想消除可以把父元素设为 font-size: 0，或用更现代的 Flex 布局。

点击按钮切换 display 取值，观察盒子是"换行堆叠"还是"并排流动"。

5.3 display 属性

决定元素"以什么身份"参与布局

display 是布局中最关键的属性之一：它决定了元素是不是块级、能不能设宽高、以及内部的子元素怎么排。

取值排布方式能否设宽高典型用途
block独占一行能容器、段落、标题
inline并排不能文字片段、链接
inline-block并排能标签、按钮
flex内部一维弹性能导航条、工具栏（第 6 章）
grid内部二维网格能页面骨架、卡片墙（第 7 章）
none不渲染—隐藏元素（退出布局树）

⭐ 关键点：display 不只管自己，还管下一代子元素怎么排—— 给父元素设 display: flex 或 grid，子元素才会按弹性/网格规则排列。 这正是第 6、7 章的核心。
注意：display: none 与 visibility: hidden 不同—— 前者完全脱离布局，后者仍占着位置。 

/* 让并排的三个盒子用弹性/网格布局 */
.toolbar { display: flex; gap: 10px; }
.wall    { display: grid; grid-template-columns: repeat(3, 1fr); }

/* 隐藏元素：两种方式效果不同 */
.gone    { display: none; }        /* 不占位 */
.invisible { visibility: hidden; } /* 仍占位 */

⭐ 关键点解释：切换 display 会触发浏览器重新计算布局（reflow）， 比只改颜色的开销大得多。所以做动画时不要用 display 过渡， 而应使用 opacity / transform。

点击不同取值，观察同一组盒子在 block / inline / inline-block 下的排布差异。
