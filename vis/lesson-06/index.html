6.1 主轴与交叉轴

想理解 Flexbox，先记住"两根轴"

给父元素写上 display: flex，它就变成了一个 弹性容器，里面的子元素成为 弹性项目，自动按"轴"来排列。

🧭 两根轴

主轴（main axis）：项目排列的方向，由 flex-direction 决定。
交叉轴（cross axis）：与主轴垂直的方向。

  • flex-direction: row（默认）：主轴水平向右，交叉轴垂直向下。
  • flex-direction: column：主轴垂直向下，交叉轴水平向右。
  • 加上 -reverse 后缀（如 row-reverse）则方向反转。

⭐ 关键点：Flexbox 的所有对齐属性都以轴为参照—— justify-content 管主轴，align-items 管交叉轴。 一旦 flex-direction 从 row 改成 column，这两个属性的效果就跟着"转 90°"。 记住这一点，就不用死记属性表了。 

/* 开启弹性布局 */
.container {
  display: flex;
  flex-direction: row;  /* row | column | row-reverse | column-reverse */
  gap: 12px;              /* 项目之间的间距（推荐，取代 margin 技巧） */
}

⭐ 关键点解释：display: flex 写在父元素上， 影响的是直接子元素的排布方式。
注意：弹性项目会自动"弹性化"—— 默认 flex-shrink: 1，所以容器变窄时项目会被压缩， 这就是为什么有时盒子会"变形"。

切换 flex-direction，观察主轴方向如何改变项目的排列。

6.2 对齐与分布

justify-content 管主轴，align-items 管交叉轴

Flexbox 最常用的场景就是"把一个东西居中"或"把几个东西均匀分布"，这靠两组属性完成。

属性作用轴常用取值
justify-content主轴flex-start / center / space-between / space-around / space-evenly
align-items交叉轴stretch / flex-start / center / flex-end
gap项目间距任意长度，如 12px

⭐ 关键点：水平垂直双居中的经典三行代码—— display: flex; justify-content: center; align-items: center; 这三行几乎能解决初学者 80% 的居中需求，也是 Flexbox 最受欢迎的用途。
注意：align-items: stretch（默认）会拉伸项目高度， 想保持项目自身高度就要显式设为 flex-start。 

/* 水平垂直双居中 —— 最经典的用法 */
.center {
  display: flex;
  justify-content: center;  /* 主轴居中 */
  align-items: center;      /* 交叉轴居中 */
}

/* 两端对齐的导航条 */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

⭐ 关键点解释：space-between 把剩余空间全部塞到项目之间 （两端贴边），正是导航栏"左 Logo 右菜单"的标准做法； 而 space-around 会在两端也留出空间，视觉上更松散。

分别选择 justify-content 与 align-items，实时观察一排盒子的位置变化。

6.3 弹性伸缩

让项目按比例瓜分剩余空间

Flexbox 之所以叫"弹性"，是因为项目可以按比例分配容器中的剩余空间。控制它的是三个属性：

  • flex-grow：剩余空间分给它的"份数"，默认 0（不参与分配）。
  • flex-shrink：空间不够时收缩的比例，默认 1。
  • flex-basis：分配前的初始尺寸，默认 auto（由内容决定）。

⭐ 关键点：flex: 1 是这三个属性的简写 （等价于 1 1 0%），意思是"平均瓜分剩余空间"。 让三个盒子 flex: 1 2 3，它们就会按 1:2:3 的比例分宽—— 这是做自适应分栏最常用的手段。 

.item { flex: 1; }        /* 平均分 */

.sidebar { flex: 1; }      /* 侧栏占 1 份 */
.main    { flex: 3; }      /* 主区占 3 份 */

/* 不想被压缩的固定宽度项 */
.avatar { flex: 0 0 48px; }

⭐ 关键点解释：flex: 0 0 48px 表示 "不伸长、不压缩、固定 48px"，常用于头像、图标这类不希望变形的元素。
常见坑：在省略写法中不要只写一个数字又期望它固定宽度， flex: 1 的 basis 是 0%，会让项目忽略自身宽度。

拖动三个 flex-grow 滑块，观察剩余空间如何按比例分配。
