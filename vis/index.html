▶️ 使用方式

这是一个零依赖的静态站点，不需要安装任何东西。

📖 学生自学

按章节顺序过一遍，每章先看 讲解，再看 关键代码，最后到 演示 里自己动手拖一拖、改一改；学完做一次 📝 测验 检验掌握程度。

🥇 动手做一个真的

想真正掌握布局，就去 🧪 实战环节：按第 9 章的真实案例，自己一步步手写 HTML / CSS 搭出个人作品集网站 —— 实时预览、分级提示、每关自动检查，成品还能导出成网页。

💻 教师备课时

每章的 tab 可以自由切换，适合一边讲原理、一边切到演示现场调参数，边讲边演。

📶 本地运行

在项目根目录执行 python -m http.server 8080，浏览器打开 http://localhost:8080 即可。

ℹ️ 关于本站

🛠️ 技术栈

零依赖、零构建：纯 HTML + CSS + JavaScript（ES Modules）。不依赖任何框架，也不需要 npm 打包。

🎯 设计原则

动手为中心：每个知识点都配一个可以实时调参的演示，看得见、改得动、记得住。

🎨 配色体系

全站配色集中于 tokens.css 的设计令牌，改一处即可整体换肤，支持系统深色模式。

🧱 布局方式

门户使用 CSS Grid 响应式卡片墙；章节页使用「顶栏 + 左侧目录 + 右侧正文」的两栏布局。
