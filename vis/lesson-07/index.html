7.1 网格基础

先划列，再放东西

Flexbox 是一维的（只能管一个方向），而 Grid 是二维的——行和列可以同时定义，特别适合页面骨架和卡片墙。

🔲 三条核心语句

display: grid 开启网格容器；
grid-template-columns 定义列；
grid-template-rows 定义行。

  • fr 是 Grid 专用的"剩余空间份额"单位，1fr 2fr 表示后一列是前一列的 2 倍宽。
  • repeat(3, 1fr) 是 1fr 1fr 1fr 的简写。
  • gap 同时控制行间距与列间距，也可以用 row-gap / column-gap 单独设置。

⭐ 关键点：Flexbox 的 flex: 1 是"分剩余空间"， Grid 的 1fr 也是"分剩余空间"，但 fr 更彻底—— 它连 gap 占掉的空间都会先扣掉再分，所以不会因为间距而溢出。

👉 在案例里看它

案例用两套网格：骨架用 12 列（9.2），卡片墙用自适应列（9.6）。

.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;  /* 三列，比例 1:2:1 */
  gap: 16px;
}

/* 等价写法：重复 3 次 1fr */
.grid-3 { grid-template-columns: repeat(3, 1fr); }

⭐ 关键点解释：用 fr 而不是百分比（如 33.33%）， 可以彻底避免"百分比 + gap 超过 100% 导致换行/溢出"的经典问题。

拖动滑块改变列数与比例系数，观察网格如何重新划分。

7.2 自动填充

不用媒体查询也能自适应列数

如果每次都写死 repeat(3, 1fr)，屏幕一窄卡片就会被挤扁。Grid 提供了一个"自动响应"的写法：

🔁 repeat(auto-fit, minmax(最小值, 1fr))

含义是：每列至少 minmax 里的最小值那么宽，能塞几列就塞几列，剩下的空间平均分。

写法行为
auto-fit自动填充，多余的空列会塌缩，卡片拉伸铺满
auto-fill自动填充，但保留空列，卡片不拉伸

⭐ 关键点：repeat(auto-fit, minmax(240px, 1fr)) 是做卡片墙的万能公式——不用写任何媒体查询， 卡片就会自动从 4 列 → 3 列 → 2 列 → 1 列随屏幕收窄而重排。 本站门户首页的卡片墙用的正是这一行。

👉 在案例里看它

作品集卡片墙就是 repeat(auto-fit, minmax(260px, 1fr))，全程没写一行媒体查询，见 9.6 卡片墙。

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 24px;
}

⭐ 关键点解释：把最小值调大（如 320px），列数就会更早减少； 调小则一屏能塞更多列。minmax 的第二项用 1fr 能让最后一行"凑不满"的卡片也拉伸到与整行等宽。

拖动"容器宽度"和"最小列宽"，观察卡片自动重排的过程。

7.3 网格定位

让某个项目横跨多列 / 多行

网格划好之后，可以让某个项目跨越若干单元格，从而做出"大标题 + 小卡片"的版式。

  • grid-column: span 2：横向跨 2 列。
  • grid-row: span 2：纵向跨 2 行。
  • grid-column: 1 / 3：从第 1 条网格线到第 3 条线（即占 2 列）。
  • grid-area: 行起 / 列起 / 行止 / 列止：一次性指定位置。

⭐ 关键点：注意 Grid 的线编号是从 1 开始， 并且有"结束线"，所以占 2 列是 1 / 3 而不是 1 / 2。 另外 grid-area 还能配合 grid-template-areas 用"画地图"的方式描述整个页面布局，可读性极高。

👉 在案例里看它

首屏和关于我都用「更具体的 .hero .grid」覆盖 12 列，这就是网格定位思路，见 9.4 首屏 Hero。

/* 让某一项横跨两列 */
.hero-card { grid-column: span 2; }

/* 用"画地图"描述页面骨架 */
.layout {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }

⭐ 关键点解释：grid-template-areas 让布局结构 在 CSS 里"看得见"。第 4 章的圣杯布局就是用它实现的—— 这比传统的 float 或 flex 方案清晰得多。

切换"跨列数"，观察被选中卡片如何占据多个格子。
