1.1 对齐：建立秩序

为什么有些页面"一看就很专业"

在写任何布局代码之前，先要回答一个设计问题：这个页面的元素，靠哪条线站队？

优秀的页面有一个共同点——你在页面上画不出几条"游离"的线。所有元素的边缘都落在少数几条看不见的参考线上，这就是对齐。

📏 对齐的三条实践规则

1. 一条边原则：一组内容至少共用一条对齐线（通常左对齐）。
2. 不要混用：同一组元素不要有的居中、有的左对齐。
3. 内外一致：容器内边距对齐、标题与正文左右边界对齐。

⭐ 关键点：初学者最容易犯的错是"凭感觉摆放"—— 这个盒子 12px、那个 18px，看起来都在左边，实际没有一条线是齐的。
正确做法：先在心里（或纸上）画出列线，再让所有元素对齐到这些线上。 这就是第 3 章要讲的"栅格系统"。

👉 在案例里看它

「相关元素落在同一条参考线上」就是 9.2 骨架与栅格 让 6 个区块左右边界对齐做的事，实战环节 2 会验收它。

/* 用 Flex 建立一条统一的对齐线 */
.row {
  display: flex;
  align-items: center;   /* 垂直方向也对齐 */
  gap: 12px;
}

/* 多个区块共用同一条左边线 */
.container { padding: 0 24px; }   /* 统一内边距，边界自然对齐 */

⭐ 关键点解释：gap 比给每个元素写 margin 更容易保持对齐， 因为它不会在首尾多出一份间距，边界位置永远可预测。

点击按钮切换「未对齐 / 已对齐」，直观感受对齐线带来的秩序感。

1.2 亲密性与留白

让"相关的"靠得近，让"不相关的"离得远

亲密性原则：逻辑上相关的内容，在视觉上就应该靠得更近；不相关的，就要拉开距离。

这条原则的力量在于——它不需要任何边框或分割线，就能让人"自动看出分组"。

🫧 留白不是浪费

留白（whitespace）指的是元素之间"空"出来的区域。 它不是"没用的地方"，而是：
· 用来分组（组内紧、组间松）
· 用来聚焦（周围越空，中间越显眼）
· 用来控制节奏（疏密有致，读起来不累）

⭐ 关键点：判断分组是否成功有一个简单标准—— 组内间距 < 组间间距，而且差距要明显（比如 8px vs 32px，而不是 16px vs 20px）。
常见错误：所有元素间距都一样，导致"看不出哪几个是一伙的"， 读者只能靠文字去理解结构。

👉 在案例里看它

案例里卡内间距 8px、卡间 24px（9.6 卡片墙），正是「组内紧、组间松」，实战环节 6 要求照做。

/* 组内紧：用 gap 控制；组间松：用 margin 拉开 */
.group {
  display: flex;
  flex-direction: column;
  gap: 8px;              /* 组内：紧 */
  margin-bottom: 32px;      /* 组间：松 */
}

⭐ 关键点解释：用"组内 gap + 组间 margin"这个两层间距结构， 比给每个元素写死 margin 更容易维护—— 调整组内密度只动 gap，调整分组间隔只动 margin-bottom。

拖动「组内间距」与「组间间距」，观察分组感什么时候才真正出现。

1.3 对比与视觉层次

让读者第一眼看到最重要的东西

一个页面不可能所有内容都同等重要。视觉层次就是"用视觉手段告诉读者先看什么、后看什么"。

手段怎么做效果
大小标题字号远大于正文最强，最容易被感知
粗细关键信息加粗强，且不占空间
颜色主色 / 深色突出，弱化用灰中，需注意对比度
间距重要内容周围留更多空弱但很高级
位置放左上 / 居中 / 首屏取决于阅读模式

⭐ 关键点：层次要有"跨度"才有意义。 18px 和 20px 的差别几乎看不出来，等于没做层次； 16px 配 32px 配 48px 这样拉开档位，层次才清晰。
建议：全站字号只保留 4～5 档（如 48 / 32 / 20 / 16 / 13）， 并写进第 3 章的"间距与字号节奏"里统一管理。

👉 在案例里看它

数字 30px、单位 14px、说明 12px 的三档落差见 9.7 数据统计区；实战环节 7 会检查字号跨度。

/* 用 CSS 变量固定"字号档位"，保证全站层次一致 */
:root {
  --fs-hero: 48px;
  --fs-h2:   32px;
  --fs-h3:   20px;
  --fs-body: 16px;
  --fs-meta: 13px;
}

.title    { font-size: var(--fs-h2);  font-weight: 700; }
.subtitle { font-size: var(--fs-body); color: var(--c-text-soft); }
.highlight{ color: var(--c-primary); }

⭐ 关键点解释：站点本身已经这么做了—— 所有字号、颜色都来自 tokens.css。 把"层次"变成少数几个可复用的档位，是保持全站统一的关键。

调整标题/正文的字号与颜色，观察"层次跨度"多大时主次才一目了然。

1.4 重复与统一

第四个原则：让页面"看起来是一个整体"

到这里，四个基础原则已经讲完三个。补上最后一个——重复（Repetition）： 相同的元素，用相同的方式呈现。

原则一句话理解缺少它会怎样
对齐 Alignment元素边缘落在共同的线上页面凌乱、不专业
亲密性 Proximity相关的靠近，无关的拉开看不出分组、阅读费力
对比 Contrast重要的大而重，次要的弱下去没有重点、读者迷茫
重复 Repetition同类元素长相一致像拼凑的、不成体系

这四条合称 CRAP 原则（Contrast / Repetition / Alignment / Proximity）， 是排版与布局设计里最经典、最实用的四把尺子。

🔁 "重复"具体重复什么？

颜色（主色只用一个）· 字体（全站 1～2 款）· 圆角（统一半径）· 间距（走同一套档位）· 按钮与标签样式 · 图标风格 · 阴影强度。

⭐ 关键点：设计令牌（design tokens）就是"重复原则"的工程实现。 把颜色、间距、圆角抽成变量，本质上就是强制全站"重复使用同一批值"。
反过来，如果每个卡片都单独调一次圆角和阴影，页面迟早会变得"四不像"。

👉 在案例里看它

案例里 4 张卡片共用同一套圆角、内边距与边框（9.6 卡片墙），这就是「成套感」的来源。

/* 重复 = 全站共用同一批值（不重复 = 每个元素各写一套） */
:root {
  --radius: 12px;       /* 圆角只定义一次 */
  --space:  16px;
  --shadow: 0 4px 16px rgba(0,0,0,.08);
}

.card, .panel, .dialog {
  border-radius: var(--radius);
  box-shadow: var(--shadow);
  padding: var(--space);
}

⭐ 关键点解释：选择器可以一次写多个（.card, .panel, .dialog）， 这也是"重复"在 CSS 里的直接体现—— 凡是长得一样的元素，就不应该有两份样式定义。

切换「各自为政 / 统一规范」，观察三张卡片的一致性差异。

1.5 格式塔原理

人眼是怎么"自动分组"的

前面讲的原则都很"实操"，但它们背后有一套心理学依据——格式塔原理（Gestalt）。 它解释了人的眼睛为什么会自动把某些元素看成一伙的。

原理含义在布局中怎么用
靠近 Proximity距离近的自动成组用间距分组（＝ 1.2 亲密性）
相似 Similarity长得像的自动成组同样式＝同类内容；不同色＝不同类
共同区域 Common Region同一容器内自动成组卡片、边框、浅色底的理论依据
闭合 Closure残缺的形状会被脑补完整不必把所有边框都画出来
连续 Continuity沿一条线排列的被视为一组对齐到同一列＝天然的一组

⭐ 关键点："卡片"这种设计形式，本质上是"共同区域"原理的应用—— 给一块内容加个背景和边框，人眼立刻知道"这些内容是一家的"， 不需要任何文字说明。
但要注意：共同区域一旦滥用，页面会变成"一堆框"。 能用间距分组时就别画框（靠近原理更轻量）。

👉 在案例里看它

卡片用背景 + 边框把内容框成一组，属于「共同区域」原则，见 9.6 卡片墙。

/* 用"共同区域"分组：加背景 + 圆角，人眼自动归组 */
.card {
  background: var(--c-surface);
  border-radius: var(--radius);
  padding: var(--space);
}

/* 用"相似"区分类型：同一类内容用同一种样式 */
.tag--new  { background: var(--c-primary-weak); color: var(--c-primary); }
.tag--hot  { background: var(--c-accent-weak);  color: var(--c-accent); }

⭐ 关键点解释：相似 ≠ 一样。 "相似"是"看起来属于同一类"，允许有区分（如上例的 NEW / HOT）， 关键是区分要成体系，而不是每个标签一种颜色。

切换「纯间距 / 加共同区域 / 再加相似区分」，观察分组感知如何一步步变清晰。

1.6 视觉平衡与节奏

页面"站不站得稳"，说的是视觉重量

最后一个理论视角：把页面想象成一个天平。每个元素都自带"重量"， 布局就是把这些重量摆稳。

⚖️ 什么让元素"更重"？

面积更大 · 颜色更深 / 更饱和 · 对比度更高 · 形状更复杂 · 周围留白更多（被孤立的东西更显眼）。

平衡方式特点适用场景
对称平衡左右镜像，稳重、正式官方页面、正式场合
非对称平衡用"大 vs 多小"或"深 vs 浅"配平现代感、活泼（更常见）

节奏：疏密要交替

如果每个区块的间距都一样，页面会像"一条直线"一样平淡。 节奏指的是：紧一段、松一段，形成呼吸与韵律。

⭐ 关键点：留白不是"剩下来的空间"，而是"主动分配的空间"。 新手常常把页面塞满，怕"浪费"；而专业做法是—— 先决定哪块内容最重要，再给它最多的留白。
经验法则：重要内容周围的留白，应不少于次要内容的 2 倍。

👉 在案例里看它

首屏用 7fr 5fr 做非对称平衡、留白用最大档位，见 9.4 首屏 Hero；实战环节 4 要求左侧比右侧宽。

/* 用不同档位的间距制造节奏（而不是全部一样） */
.hero      { padding: var(--space-xl) 0; }  /* 松：核心区 */
.features  { padding: var(--space-lg) 0; }  /* 中 */
.meta      { padding: var(--space-sm) 0; }  /* 紧：附属信息 */

/* 非对称平衡：左边大图，右边用「多个小块 + 文字」配平 */
.split { display: grid; grid-template-columns: 7fr 5fr; }

⭐ 关键点解释：非对称平衡常用 7fr 5fr、8fr 4fr 这类非均分比例，而不是死板的 1fr 1fr—— 因为左右两边的"视觉重量"本来就不一样，用比例去补偿才平衡。

拖动参数改变左右两侧的视觉重量，观察"天平"什么时候会失衡。
