4.1 圣杯布局

页头 + 双侧栏 + 主内容 + 页脚

"圣杯布局"是一个经典考题：页头、页脚、左右两侧栏、中间主内容区， 要求主内容区优先、两侧栏定宽、整体自适应。

🏆 现代实现：grid-template-areas

用 Grid 的"画地图"写法，四行 CSS 就能描述整个页面骨架， 比传统 float / 负 margin 方案清晰得多。 

.layout {
  display: grid;
  grid-template-columns: 200px 1fr 180px;
  grid-template-areas:
    "header  header  header"
    "left    main    right"
    "footer  footer  footer";
}

⭐ 关键点：grid-template-areas 的可读性是最大优势—— 你一眼就能从 CSS 里"看出"页面长什么样。
小屏适配：只要在媒体查询里把 areas 重画成单列 （每行都写同一个名字），整个页面就变成上下堆叠，不用改任何 HTML。 

.layout {
  display: grid;
  grid-template-columns: 200px 1fr 180px;
  grid-template-areas:
    "header header header"
    "left   main   right"
    "footer footer footer";
  gap: 12px;
}
.header { grid-area: header; }
.left   { grid-area: left; }
.main   { grid-area: main; }
.right  { grid-area: right; }
.footer { grid-area: footer; }

/* 小屏：全部堆成一列 */
@media (max-width: 700px) {
  .layout {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header" "left" "main" "right" "footer";
  }
}

⭐ 关键点解释：areas 的每一行字符串代表"一行网格"， 同一个名字横跨几列就写几遍。写错格子数会导致整条规则失效，所以要按列数对齐。

切换布局变体，观察同一份 HTML 在不同 grid-template-areas 下的变化。

4.2 卡片墙

列表页最常见的一种布局

卡片墙（card grid）几乎是每个网站都会用到的布局：一堆等宽的方块， 随屏幕宽度自动改变列数。

⭐ 关键点：一行 CSS 搞定—— grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))。 它同时解决了三个问题：列数自适应、列宽不小于最小值、 剩余空间平均分配，完全不需要媒体查询。
本站的门户首页用的就是这一行。 

.wall {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 20px;
}

/* 卡片本身：用 flex 让"底部按钮"始终贴底 */
.card {
  display: flex;
  flex-direction: column;
  padding: 20px;
}
.card .cta { margin-top: auto; }

⭐ 关键点解释：margin-top: auto 是让卡片内的元素 "推到最底部"的常用技巧——在 flex 列布局里，auto 外边距会吃掉所有剩余空间。 另外 minmax(240px, 1fr) 里的 1fr 不能省， 否则卡片不会拉伸、右侧会留白。

调整"最小列宽"和"间距"，观察卡片数量与呼吸感的变化。

4.3 仪表盘栅格

不同尺寸的模块如何共存

仪表盘（dashboard）的难点在于：模块大小不一，有的大图表要跨列，有的小指标只占一格。

⭐ 关键点：仍然用 Grid，但采用" 固定列数 + 局部跨列"的思路—— 先把容器划成固定的 N 列（如 4 列）， 再让大模块 grid-column: span 2、全宽模块 span 4。
这比"给每个模块写死宽度"灵活得多，且天然对齐。 

.dashboard {
  display: grid;
  grid-template-columns: repeat(4, 1fr);   /* 基准 4 列 */
  gap: 14px;
}

.w2 { grid-column: span 2; }   /* 占两格 */
.w4 { grid-column: span 4; }   /* 整行 */

/* 小屏降为 2 列，跨列自动收缩 */
@media (max-width: 720px) {
  .dashboard { grid-template-columns: repeat(2, 1fr); }
  .w4 { grid-column: span 2; }
}

⭐ 关键点解释：用 span 而不是写死 1 / 3， 好处是同一套类在小屏改成 2 列后仍然成立（span 2 就是整行了）， 只需要覆盖少数几个"超宽"模块即可。

切换预设布局，观察模块在不同跨列方案下的排布。
