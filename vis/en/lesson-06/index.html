6.1 The Main Axis and the Cross Axis

To understand Flexbox, remember "the two axes" first

Put display: flex on a parent and it becomes a flex container; its children become flex items and arrange themselves along an "axis" automatically.

🧭 The two axes

Main axis: the direction the items are laid out in, decided by flex-direction.
Cross axis: the direction perpendicular to the main axis.

  • flex-direction: row (the default): the main axis runs horizontally to the right, the cross axis vertically downwards.
  • flex-direction: column: the main axis runs vertically downwards, the cross axis horizontally to the right.
  • Adding a -reverse suffix (such as row-reverse) flips the direction.

⭐ Key point: every Flexbox alignment property is measured against the axes — justify-content controls the main axis and align-items controls the cross axis. Once flex-direction changes from row to column, the effect of both properties "rotates 90°". Remember that and you never have to memorise a property table.

👉 See it in the case

The nav’s .inner has a row main axis, which is what puts the logo and menu at opposite ends — 9.3 Top nav bar. Lab step 3 reads the computed style.

/* Turn on flex layout */
.container {
  display: flex;
  flex-direction: row;  /* row | column | row-reverse | column-reverse */
  gap: 12px;              /* spacing between items (preferred over margin tricks) */
}

⭐ Key point: display: flex goes on the parent and affects how the direct children are laid out.
Note: flex items automatically become "flexible" — the default is flex-shrink: 1, so items get squeezed when the container narrows. That is why boxes sometimes seem to "deform".

Switch flex-direction and watch how the main axis changes the way items are arranged.

6.2 Alignment and Distribution

justify-content controls the main axis, align-items the cross axis

The most common Flexbox scenario is "center one thing" or "distribute several things evenly", and that is handled by two groups of properties.

PropertyAxis affectedCommon values
justify-contentMain axisflex-start / center / space-between / space-around / space-evenly
align-itemsCross axisstretch / flex-start / center / flex-end
gapSpacing between itemsany length, e.g. 12px

⭐ Key point: the classic three lines for centering both ways — display: flex; justify-content: center; align-items: center; These three lines cover roughly 80% of a beginner's centering needs, and they are Flexbox's most popular use.
Note: align-items: stretch (the default) stretches item heights; to keep items at their own height, set flex-start explicitly.

👉 See it in the case

In the case justify-content: space-between arranges the nav while align-items: center keeps its text vertically centred — 9.3 Top nav bar.

/* Center both horizontally and vertically — the most classic use */
.center {
  display: flex;
  justify-content: center;  /* main axis centered */
  align-items: center;      /* cross axis centered */
}

/* A nav bar with items pushed to both ends */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

⭐ Key point: space-between pushes all the leftover space between the items (so the two ends sit flush) — the standard way to build "logo on the left, menu on the right" in a nav bar. space-around, by contrast, also leaves space at the two ends, which reads as looser.

Pick a justify-content and an align-items value and watch the row of boxes move in real time.

6.3 Flexing

Let items share the leftover space in proportion

Flexbox is called "flexible" because items can share the container's leftover space in proportion. Three properties control that:

  • flex-grow: the "share" of the leftover space handed to this item; defaults to 0 (it does not take part).
  • flex-shrink: the rate at which it shrinks when space runs short; defaults to 1.
  • flex-basis: the initial size before any distribution; defaults to auto (decided by content).

⭐ Key point: flex: 1 is shorthand for those three properties (equivalent to 1 1 0%) and means "split the leftover space evenly". Give three boxes flex: 1 2 3 and they divide the width in a 1:2:3 ratio — the most common technique for building adaptive columns.

👉 See it in the case

The card’s “View details” link uses margin-top: auto to pin itself to the bottom, so uneven cards still align — 9.6 Card wall.

.item { flex: 1; }        /* equal split */

.sidebar { flex: 1; }      /* sidebar takes 1 share */
.main    { flex: 3; }      /* main area takes 3 shares */

/* A fixed-width item that must not be squeezed */
.avatar { flex: 0 0 48px; }

⭐ Key point: flex: 0 0 48px means "don't grow, don't shrink, fixed at 48px", which is what you use for avatars and icons that must not distort.
Common trap: don't write a single number in the shorthand and expect a fixed width — the basis of flex: 1 is 0%, which makes the item ignore its own width.

Drag the three flex-grow sliders and watch how the leftover space is shared out in proportion.
