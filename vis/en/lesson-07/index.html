7.1 Grid Basics

Draw the columns first, then place things in them

Flexbox is one-dimensional — it can only govern one direction at a time. Grid is two-dimensional: rows and columns are defined together, which makes it ideal for page skeletons and card walls.

🔲 Three core statements

display: grid turns on a grid container;
grid-template-columns defines the columns;
grid-template-rows defines the rows.

  • fr is Grid's own "share of the leftover space" unit — 1fr 2fr means the second column is twice as wide as the first.
  • repeat(3, 1fr) is shorthand for 1fr 1fr 1fr.
  • gap controls row and column spacing at once; you can also set them separately with row-gap / column-gap.

⭐ Key point: Flexbox's flex: 1 means "share the leftover space" and Grid's 1fr means the same — but fr goes one step further: it subtracts the space taken by gap before dividing, so nothing ever overflows because of spacing.

👉 See it in the case

The case uses two grids: 12 columns for the skeleton (9.2) and an adaptive one for the wall (9.6).

.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;  /* three columns, ratio 1:2:1 */
  gap: 16px;
}

/* Equivalent form: repeat 1fr three times */
.grid-3 { grid-template-columns: repeat(3, 1fr); }

⭐ Key point: using fr instead of percentages (such as 33.33%) completely avoids the classic problem where "a percentage plus gap adds up to more than 100%" and causes wrapping or overflow.

Drag the sliders to change the column count and the ratio, and watch how the grid re-divides.

7.2 Auto-Fill

An adaptive column count without any media query

If you hard-code repeat(3, 1fr) every time, the cards get squashed as soon as the screen narrows. Grid offers an "automatically responsive" form instead:

🔁 repeat(auto-fit, minmax(minimum, 1fr))

It means: each column is at least as wide as the minimum inside minmax; fit in as many columns as will go, then share the remaining space evenly.

FormBehaviour
auto-fitAuto-fills, and surplus empty tracks collapse so the cards stretch to fill
auto-fillAuto-fills, but keeps the empty tracks, so the cards do not stretch

⭐ Key point: repeat(auto-fit, minmax(240px, 1fr)) is the universal formula for a card wall — without writing a single media query, the cards rearrange themselves from 4 columns → 3 → 2 → 1 as the screen narrows. This site's portal home page uses exactly that line.

👉 See it in the case

The portfolio wall is repeat(auto-fit, minmax(260px, 1fr)) with not a single media query — 9.6 Card wall.

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 24px;
}

⭐ Key point: raise the minimum (say to 320px) and the column count drops earlier; lower it and more columns fit on one screen. Using 1fr as the second value of minmax also lets the incomplete cards in the last row stretch to the full row width.

Drag "container width" and "minimum column width" and watch the cards rearrange themselves.

7.3 Grid Placement

Make an item span several columns or rows

Once the grid is drawn, you can make an item span a number of cells, which is how "a big headline plus small cards" layouts are built.

  • grid-column: span 2: spans 2 columns horizontally.
  • grid-row: span 2: spans 2 rows vertically.
  • grid-column: 1 / 3: from grid line 1 to grid line 3 (i.e. 2 columns).
  • grid-area: row-start / column-start / row-end / column-end: sets the position in one go.

⭐ Key point: note that Grid numbers its lines starting from 1, and that there is an "end line", so spanning 2 columns is 1 / 3 rather than 1 / 2. On top of that, grid-area can combine with grid-template-areas to describe an entire page layout by "drawing a map", which is extremely readable.

👉 See it in the case

The hero and about sections override the 12 columns with the more specific .hero .grid — grid placement in practice, at 9.4 Hero.

/* Make one item span two columns */
.hero-card { grid-column: span 2; }

/* Describe a page skeleton by "drawing a map" */
.layout {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }

⭐ Key point: grid-template-areas makes the layout structure visible right inside the CSS. Chapter 4's holy grail layout is built exactly this way — far clearer than the traditional float or flex approaches.

Switch "columns spanned" and watch the selected card occupy several cells.
