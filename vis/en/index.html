▶️ How to use this site

This is a zero-dependency static site — there is nothing to install.

📖 Studying on your own

Work through the chapters in order. In each one, read the Explanation first, then the Key code, and finally open the Demo to drag the sliders and change values yourself.

💻 Preparing a class

The tabs switch freely, so you can explain the principle and jump straight to the live demo to adjust parameters on the spot — teaching and demonstrating in one go.

📶 Running it locally

Run python -m http.server 8080 in the project root, then open http://localhost:8080 in your browser.

ℹ️ About this site

🛠️ Tech stack

Zero dependencies, zero build: plain HTML + CSS + JavaScript (ES Modules). No framework, and no npm bundling.

🎯 Design principle

Hands-on first: every concept comes with a demo you can adjust in real time — you see it, you change it, you remember it.

🎨 Color system

Every color on the site comes from the design tokens in tokens.css — reskin the whole site by editing one file. Dark mode follows your system setting.

🧱 Layout approach

The portal uses a responsive CSS Grid card wall; chapter pages use a two-column layout — a sticky top bar, a left-hand outline, and the content on the right.
