1.1 Alignment: Creating Order

Why some pages "just look professional"

Before writing a single line of layout code, answer one design question: which line do the elements on this page line up on?

Good pages share one trait — you cannot draw many "stray" lines on them. Every element's edges land on a small number of invisible reference lines, and that is alignment.

📏 Three practical rules of alignment

1. The one-edge rule: a group of content shares at least one alignment line (usually the left one).
2. Don't mix: within one group, don't center some elements and left-align others.
3. Consistent inside and out: the container's padding lines up, and headings share the same left and right edges as the body text.

⭐ Key point: the mistake beginners make most often is placing things by feel — this box at 12px, that one at 18px. They look left-aligned, but no two edges actually match.
The right approach: first draw the column lines in your head (or on paper), then align everything to them. That is what Chapter 3 calls a "grid system".

👉 See it in the case

“Related elements on one shared edge” is what 9.2 Skeleton and grid does to all six blocks; lab step 2 checks it.

/* Establish one shared alignment line with Flexbox */
.row {
  display: flex;
  align-items: center;   /* aligns vertically too */
  gap: 12px;
}

/* Several blocks share the same left edge */
.container { padding: 0 24px; }   /* one padding, so edges line up on their own */

⭐ Key point: gap keeps alignment far better than writing a margin on every element, because it never adds an extra slot of space at the first or last item — the edges stay predictable.

Click the button to switch between "misaligned" and "aligned", and feel the sense of order that alignment lines create.

1.2 Proximity and Whitespace

Keep related things close, push unrelated things apart

Proximity: content that is logically related should sit closer together visually, and unrelated content should be pushed apart.

The strength of this principle is that it needs no border and no divider to make people "see the groups" automatically.

🫧 Whitespace is not wasted space

Whitespace is the empty area between elements. It is not "space doing nothing"; it is there to:
· group things (tight inside a group, loose between groups)
· focus attention (the emptier the surroundings, the more the center stands out)
· control rhythm (varying density keeps reading effortless)

⭐ Key point: there is a simple test for whether grouping works — spacing inside a group < spacing between groups, and the difference has to be obvious (8px vs 32px, not 16px vs 20px).
Common mistake: giving every element the same spacing, so "you can't tell which items belong together" and readers must rely on the words to understand the structure.

👉 See it in the case

In the case the padding inside a card is 8px while the gap between cards is 24px (9.6 Card wall) — tight inside, loose between. Lab step 6 asks for the same.

/* Tight inside: use gap. Loose between: use margin */
.group {
  display: flex;
  flex-direction: column;
  gap: 8px;              /* inside a group: tight */
  margin-bottom: 32px;      /* between groups: loose */
}

⭐ Key point: this two-layer spacing structure — gap inside, margin between — is easier to maintain than hard-coding a margin on every element: to change the density inside a group you touch only gap, and to change the gap between groups you touch only margin-bottom.

Drag "intra-group spacing" and "inter-group spacing" and watch when a real sense of grouping appears.

1.3 Contrast and Visual Hierarchy

Make readers see the most important thing first

Not everything on a page can matter equally. Visual hierarchy means "using visual means to tell readers what to look at first, and what comes after".

SignalHow to do itEffect
SizeHeadings far larger than body textStrongest, most easily perceived
WeightBold the key informationStrong, and costs no space
ColorEmphasize with the primary / deep color; mute with greyMedium; mind the contrast ratio
SpacingLeave more room around important contentWeak, but very refined
PositionTop-left / centered / above the foldDepends on the reading pattern

⭐ Key point: hierarchy only means something if there is a real jump in scale. 18px versus 20px is barely perceptible — that is no hierarchy at all; 16px, 32px and 48px make the levels unmistakable.
Suggestion: keep only 4–5 type sizes across the whole site (say 48 / 32 / 20 / 16 / 13) and manage them together under Chapter 3's "spacing and type scale".

👉 See it in the case

The three-step type scale (30px number, 14px unit, 12px label) is 9.7 The numbers strip; lab step 7 checks the size gaps.

/* Pin the "type scale" with CSS variables so hierarchy stays consistent site-wide */
:root {
  --fs-hero: 48px;
  --fs-h2:   32px;
  --fs-h3:   20px;
  --fs-body: 16px;
  --fs-meta: 13px;
}

.title    { font-size: var(--fs-h2);  font-weight: 700; }
.subtitle { font-size: var(--fs-body); color: var(--c-text-soft); }
.highlight{ color: var(--c-primary); }

⭐ Key point: this very site already works that way — every font size and color comes from tokens.css. Turning "hierarchy" into a handful of reusable steps is the key to staying consistent across a whole site.

Adjust the font size and color of headings and body text, and see how large the "hierarchy jump" must be before primary and secondary become obvious at a glance.

1.4 Repetition and Unity

The fourth principle: make the page "read as one whole"

We have covered three of the four foundational principles. Here is the last one — Repetition: present the same kind of element in the same way.

PrincipleIn one sentenceWhat breaks without it
AlignmentElement edges land on shared linesThe page looks messy and unprofessional
ProximityRelated items close, unrelated items apartGroups are invisible; reading takes effort
ContrastImportant things big and heavy, the rest recedeNo focal point; readers feel lost
RepetitionSame kind of element looks the sameIt looks pieced together, not systematic

Together these four are known as the CRAP principles (Contrast / Repetition / Alignment / Proximity) — the most classic and most practical set of rulers in typography and layout design.

🔁 What exactly gets repeated?

Color (one primary only) · Type (1–2 families site-wide) · Corner radius (a single radius) · Spacing (one shared scale) · Button and tag styles · Icon style · Shadow strength.

⭐ Key point: design tokens are the engineering implementation of the repetition principle. Pulling colors, spacing and radii out into variables is, in essence, forcing the whole site to "reuse the same set of values".
Conversely, if every card gets its own hand-tuned radius and shadow, the page will drift out of shape sooner or later.

👉 See it in the case

All four cards in the case share one radius, padding and border (9.6 Card wall) — that is where the “one set” feeling comes from.

/* Repetition = the site shares one set of values (no repetition = everyone rolls their own) */
:root {
  --radius: 12px;       /* the radius is defined exactly once */
  --space:  16px;
  --shadow: 0 4px 16px rgba(0,0,0,.08);
}

.card, .panel, .dialog {
  border-radius: var(--radius);
  box-shadow: var(--shadow);
  padding: var(--space);
}

⭐ Key point: a selector can list several targets at once (.card, .panel, .dialog), and that is repetition showing up directly in CSS — elements that look the same should never have two separate style definitions.

Switch between "everyone does their own thing" and "one shared spec" and compare how consistent the three cards look.

1.5 Gestalt Principles

How the eye "groups things automatically"

The principles so far are very hands-on, but there is a body of psychology behind them — the Gestalt principles. They explain why the eye automatically treats certain elements as belonging together.

PrincipleWhat it meansHow to use it in layout
ProximityThings that sit close group automaticallyGroup with spacing (= §1.2)
SimilarityThings that look alike group automaticallySame style = same kind of content; different color = different kind
Common RegionThings inside one container group automaticallyThe theory behind cards, borders and tinted backgrounds
ClosureAn incomplete shape gets completed by the brainYou do not have to draw every border
ContinuityItems along one line read as a groupAligning to one column = a natural group

⭐ Key point: the "card" pattern is essentially the common-region principle at work — give a block of content a background and a border and the eye knows at once that "these belong together", with no text needed.
But mind this: overuse common region and the page turns into "a pile of boxes". When spacing can do the job, do not draw a box (proximity is the lighter tool).

👉 See it in the case

A card frames its content with a background and a border — the Gestalt “common region” at work in 9.6 Card wall.

/* Group with a "common region": add a background + radius and the eye groups it for you */
.card {
  background: var(--c-surface);
  border-radius: var(--radius);
  padding: var(--space);
}

/* Tell types apart with "similarity": one kind of content, one kind of style */
.tag--new  { background: var(--c-primary-weak); color: var(--c-primary); }
.tag--hot  { background: var(--c-accent-weak);  color: var(--c-accent); }

⭐ Key point: similar is not the same. "Similar" means "looks like it belongs to the same family" and still allows distinctions (NEW / HOT above). What matters is that the distinctions form a system, instead of every tag getting its own color.

Switch between "spacing only", "add a common region" and "add similarity distinctions", and watch how the perception of grouping sharpens step by step.

1.6 Visual Balance and Rhythm

Whether a page "stands firm" comes down to visual weight

One last theoretical lens: picture the page as a balance scale. Every element carries its own "weight", and laying out a page is the job of positioning those weights so the whole thing stands steady.

⚖️ What makes an element "heavier"?

a larger area · a darker / more saturated color · higher contrast · a more complex shape · more whitespace around it (isolated things catch the eye more).

Balance styleCharacteristicWhere it fits
Symmetrical balanceMirrored left and right; steady and formalOfficial pages, formal occasions
Asymmetrical balanceBalanced by "one big vs several small" or "dark vs light"Modern and lively (more common)

Rhythm: alternate tight and loose

If every block has identical spacing, the page reads flat, like "one long straight line". Rhythm means tight for a stretch, loose for a stretch, creating breathing and cadence.

⭐ Key point: whitespace is not "the space that is left over" — it is "space you allocate on purpose". Beginners cram the page because they are afraid of "wasting" room; the professional move is to decide which block matters most, then give it the most whitespace.
Rule of thumb: the whitespace around important content should be at least twice that around secondary content.

👉 See it in the case

The hero balances asymmetrically with 7fr 5fr and uses the largest whitespace step — 9.4 Hero. Lab step 4 requires the left column to be wider.

/* Create rhythm with different spacing steps (instead of making everything identical) */
.hero      { padding: var(--space-xl) 0; }  /* loose: the core area */
.features  { padding: var(--space-lg) 0; }  /* medium */
.meta      { padding: var(--space-sm) 0; }  /* tight: supporting info */

/* Asymmetrical balance: a large image on the left, several small blocks + text on the right */
.split { display: grid; grid-template-columns: 7fr 5fr; }

⭐ Key point: asymmetrical balance normally uses a non-uniform ratio such as 7fr 5fr or 8fr 4fr rather than the rigid 1fr 1fr — because the two sides naturally carry different visual weight, and the ratio is what compensates for it.

Drag the parameters to change the visual weight on each side and watch when the "balance scale" tips.
