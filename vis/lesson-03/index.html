3.1 12 列栅格

给页面上所有元素一套共同的"刻度"

第 1 章讲了"要对齐"，但对齐到哪儿？答案是栅格（grid system）——把页面横向切成若干等宽的列，所有元素都按"跨几列"来摆放。

📐 栅格的四个组成部分

容器（container）：内容的最大宽度，居中显示。
列（column）：通常 12 列。
槽（gutter）：列与列之间的间距。
外边距（margin）：容器与屏幕边缘的留白。

⭐ 关键点：为什么偏偏是 12 列？ 因为 12 能被 1、2、3、4、6、12 整除—— 意味着你可以轻松做"一半(6+6)""三分之一(4+4+4)""四分之一(3×4)""三分之二(8+4)"， 不用改栅格就能适配大多数版式。这是 12 这个数字的工程优势，不是审美玄学。 

/* 最基本的 12 列栅格 */
.grid-12 {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 24px;               /* 也就是 gutter */
  max-width: 1180px;
  margin: 0 auto;            /* 容器居中 */
}

/* 元素按"跨几列"摆放 */
.col-8 { grid-column: span 8; }   /* 2/3 宽 */
.col-4 { grid-column: span 4; }   /* 1/3 宽 */

⭐ 关键点解释：用 span N 而不是写死像素宽度， 好处是改容器宽度时所有元素自动等比调整，永远保持对齐； 而且和小屏适配天然兼容（第 8 章会讲怎么降列）。

调整每个内容块跨越的列数，观察它们始终落在同一套列线上。

3.2 8pt 间距节奏

别再用 13px、17px、23px 这种"随手值"

除了横向的列，纵向也需要一套"刻度"——这就是间距体系。业界最常用的是 8pt 栅格：所有间距都是 8 的倍数。

档位数值典型用途
--space-xs4px图标与文字之间
--space-sm8px组内元素、标签间距
--space16px卡片内边距、常规间距
--space-lg24px卡片之间
--space-xl40px区块之间

⭐ 关键点：间距体系的价值不在于"数值好看"，而在于 让每一次留白决策都变成"从 5 个档位里选一个"， 而不是"临时拍一个 17px"。
这样做的直接好处：页面节奏统一、改版时成批调整、团队协作不打架。
本站的 tokens.css 就是这么定义的——你也已经看到了。 

:root {
  --space-xs: 4px;
  --space-sm: 8px;
  --space:    16px;
  --space-lg: 24px;
  --space-xl: 40px;
}

/* 用档位，而不是随手数值 */
.card    { padding: var(--space); }
.section { margin-bottom: var(--space-xl); }
.tag     { margin-right: var(--space-xs); }

⭐ 关键点解释：4px 作为最小档是有原因的—— 它足够小能处理细节，又是 8 的一半，所以"半个标准间距"也能落在体系里， 不会出现 6px、10px 这类破坏节奏的数值。

切换「随手值 / 8pt 节奏」，对比同一份内容的视觉整齐度。

3.3 对齐到栅格

保留一个"放大镜"，随时检查是否对齐

栅格画出来之后，还需要一个检查手段：把列线半透明地叠加在页面上，一眼就能看出哪些元素"跑偏了"。

🔍 常见的三种"跑偏"

1. 左右边界不齐：容器 padding 与内容 padding 叠加，导致左右不等。
2. 卡片宽度不一：用像素写死宽度，而不是 span。
3. 间距不成比例：某处 14px、另一处 22px，节奏被打断。

⭐ 关键点：调试布局时，先开栅格叠加层，再谈细节。 很多"说不清楚哪里怪"的页面，打开栅格一看全是问题。
实用技巧：给栅格叠加层加一个快捷键（例如按 G 切换）， 做布局时随手检查，比事后返工便宜得多。 

/* 栅格叠加层：绝对定位 + 半透明列 */
.overlay {
  position: absolute;
  inset: 0;
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 24px;
  pointer-events: none;   /* 不挡点击 */
}
.overlay span {
  background: rgba(15,118,110,.10);
}

⭐ 关键点解释：pointer-events: none 是关键—— 否则叠加层会挡住页面上的所有点击。调试工具一定要"无副作用"。

打开栅格叠加层，再切换「对齐 / 跑偏」，看看差异有多明显。
