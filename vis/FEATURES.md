# 页面布局教学平台 · 关键亮点

> 一个教「如何设计网页布局」的纯前端教学网站：**不用安装任何东西，双击就能上课**。
> 中英双语、22 个页面、9 章 38 个小节，配 38 个可动手的交互演示、一套自动判分的实战工作台、一张能拖动的课程知识图谱。
>
> 🔗 在线访问：门户首页 `index.html`（中文）｜ `en/index.html`（English）

## 亮点一：一个真实案例贯穿全部 9 章，知识不再「学完不知道干嘛用」

传统教程常把知识点和案例分开讲，学生学一半就迷失。本站用**同一个「个人作品集网站」**把 9 章串成一条制作流水线：

> 定目标 → 搭骨架 → 立栅格 → 做导航 → 首屏 → 关于我 → 作品墙 → 数据区 → 响应式

而且这条主线在课程里**四个地方反复可见、双向可跳**：

- 门户首页有「课程主线」时间轴，一眼看完全流程，每步标注用到第几章；
- 30 个知识小节末尾有「案例抓手」：告诉你这一节会用在最终案例的哪一步、实战的哪一关；
- 第 9 章每一步开头有「这一步用到了」：反向跳回对应的知识点小节；
- 连关键代码上都有角标：看到 `7fr 5fr` 就知道它出自第 7 章。

全站演示也只用同一套素材（同一位虚拟学员、同一个作品集），学生从头到尾在打磨**同一个页面**。

## 亮点二：38 个「真的能动手」的交互演示，不是截图

每个小节都是统一的 **📖 讲解 / ⌨️ 关键代码 / ▶️ 演示** 三标签页，边看理论边操作：

- 学**对齐**：一键切换「凭感觉乱摆 / 共用一条对齐线」，红色参考线让参差立现；
- 学**亲密性**：拖动「组内间距、组间间距」滑块，亲眼看分组感何时出现；
- 学**栅格**：拖动各区块跨列数、勾选栅格叠加层，验证元素是否落在同一套列线上；
- 学 **Flex / Grid / 响应式**：调容器宽度、列间距、断点，布局实时重排。

演示**点到标签才加载**（打开页面更快），来回切换时你调好的参数**不会被重置**。

## 亮点三：每章顶部的「小节流动路径带」—— 打开课本就有一张学习地图

每章标题下方是一张浅色氛围卡片：**01 / 02 / 03… 编号节点沿一条波浪曲线排开，一道虚线在轨道上持续流动**，像一条正在行进的学习路线。

- 节点位置与曲线由脚本读取本章目录**自动生成**，9 章中英 18 个页面零额外数据、零手工排版；
- 流动效果用原生 SVG 贝塞尔曲线 + CSS 虚线偏移动画实现，**零图片零依赖**，任何小节数量都能无缝循环；
- 当前学到的小节徽章自动点亮（实心徽章 + 脉冲圆环），随目录切换移动；
- 面板背景是白色渐变叠青绿光晕的毛玻璃质感，跟随站点主题色，**暗色模式下自动换色**；
- 手机上在卡片内部横向滑动浏览，不撑破页面；系统开启「减少动态效果」时动画自动停止。

## 亮点四：能拖动、能缩放、能导出的课程知识图谱

「这两章是什么关系？」「这个知识点在案例哪一步用得上？」——门户首页的知识图谱用一张关系图回答：

- **节点 = 篇章 / 章节 / 知识点 / 案例步骤**，**连线 = 包含 / 前置知识 / 用于案例**三种真实语义；
- 两级视图：总览 12 节点看课程骨架，一键进入 51 节点 / 121 条边的全图；
- 按住节点可**自由拖动布局，松手就停在放下的位置**，「适应窗口」一键复位；悬停高亮邻接、滚轮缩放、空白平移；
- 提供**列表视图**（键盘/读屏/手机更友好）、**一键导出 PNG**（原生 SVG 转图，不掉色）；
- 图谱数据从课程正文自动抽取生成，**图和正文永远对得上**；每次打开同一视图位置完全一致，不会「刷新就乱」。

## 亮点五：内置测验系统 —— 随机抽题、即时讲解、错题本

门户首页直接答题，不需要任何后端：

- **50 道题库**（30 选择 + 20 判断）覆盖全部章节，每轮随机抽 **8 选择 + 2 判断**，并尽量分散到不同章；
- 交卷立即出总分与**逐题解析**，每题都能跳回对应章节复习；
- 答错自动进**错题本**，历次成绩自动记录——全部保存在浏览器本地，**不上传、不追踪、无账号**。

---

## 亮点六：实战工作台 —— 在浏览器里写页面，系统自动给你「量」分

`practice.html` 把最终案例拆成 **8 个闯关环节**，左侧题目、中间 HTML/CSS 编辑器、右侧实时预览：

- 改一行代码，预览立刻刷新；可切换 **1180 桌面 / 768 平板 / 375 手机** 三档宽度亲验响应式；
- **57 个自动检查点是真的在测量**：用浏览器引擎读取元素的计算样式与坐标，判断「是不是 grid 布局、卡片间距是否 24px、窄屏是否变单列」，逐条报告通过/未通过——不是对答案自测；
- 卡住时有**分级提示**（先提示思路，不直接给答案）；进度自动保存，可导出 `.html` 作品带走；
- 预览运行在安全沙箱中，自动剔除脚本，既保证测量能力又杜绝沙箱逃逸。

## 亮点七：中英双语是「架构级」的，不是复制两份页面

- 答题、实战等交互**逻辑只有一份代码**，英文只提供一张文案覆盖表：改一个功能，中英同时生效；
- 题库与案例数据中英各一份但**逐题、逐环节一一对应**，由自检脚本强制对齐；
- 中英文页面结构逐项同构，中文加了内容忘了改英文会被自动检查拦下；
- 切换语言时保留你正在看的小节，支持 `?lang=en` 直接分享英文链接。

## 亮点八：处处打磨过的使用体验

- **深色模式**：顶栏右上角月亮/太阳按钮一键切换（选择记入 localStorage，全站记住；未手动选择时自动跟随系统），亮暗两套配色均经过对比度实测；
- **响应式**：桌面 / 平板 / 手机三档适配，22 个页面在 1440px 与 375px 宽度下均零横向溢出；
- **无障碍**：语义化标签、`aria` 标注、键盘可操作、进度条可被读屏识别；
- **设计统一**：全站配色 / 间距 / 圆角 / 阴影来自同一份设计令牌，9 章视觉语言完全一致；
- **安静可靠**：所有页面真机体检 0 个脚本报错、0 个资源 404。

---

## 亮点九：零构建的工程克制，本身就是一种教学态度

- 没有 `node_modules`、没有打包器、没有转译步骤——**「查看网页源代码」看到的就是最终源码**，初学者可以直接对照学习；
- 全站相对路径，整个文件夹拷到 U 盘双击可用，也可零配置发布到 GitHub Pages；
- 9 章共用一份样式表、一个交互引擎：新增一章不必复制粘贴逻辑；
- 自带 6 个开发自检脚本（中英结构对齐、620 处链接与 270 处锚点有效性、题库合法性、案例完整性、图谱一致性、22 页真机体检），**站点质量是脚本量出来的，不是感觉出来的**。
