# 可视化 Pandas 工作台｜数据可视化作业 03

**一次完整分析的四个动作**：**数据 → 变换 → 图表 → 代码**。这是一个跑在浏览器里的迷你 pandas 工作台：载入一张表，把 52 种变换（筛选 / 清洗 / 分组 / 透视 / 时间序列 / 合并…）串成一条流水线，实时看形状、表格与图表，最后拿到一份**可以直接复制去跑的 pandas 代码**。

- 纯 HTML + CSS + JavaScript（普通 `<script>`，不用 ES Module、不用构建），**双击 `index.html` 就能跑**，`file://` 下功能完整；
- **中英双语**（顶栏「中 / EN」）与**亮 / 暗主题**（跟随系统、可手动切换、记住偏好）；切换语言会同时换界面文案与代码注释，**列名与 pandas API 保持英文**；
- **52 种变换算子**，按 5 组归在同一个下拉里：**选择与查询**（筛选 / 选列 / 删列 / 重命名 / 排序 / 取前 N 行 / 表达式查询 / 成员筛选 / 区间筛选 / 随机抽样 / 前 N 名 / 行号切片 / 设为索引 / 重置索引）、**清洗**（类型转换 / 新增计算列 / 删除缺失行 / 填充缺失值 / 去除重复行 / 值替换 / 字符串处理 / 区间截断 / 转时间类型 / 转分类类型 / 标记重复 / 等距分箱 / 等频分箱 / 独热编码）、**重塑**（逆透视 melt）、**分组与统计**（分组聚合 / 频数统计 / 透视表 / 交叉表 / 相关矩阵 / 描述统计 / 协方差 / 多列聚合 / 组内广播 / 按组过滤 / 排名 / 累计 / 滚动窗口 / 扩展窗口 / 差分 / 平移 / 时间重采样 / 时间成分 / 日期偏移）、**合并**（两表连接 / 纵向拼接 / 按键连接 / 补齐缺失）；每一步都能上移 / 下移 / 删除；**某一步出错只标红这一步**，其余步骤照常计算；
- **10 类自绘 SVG 图表**（条形 / 横向条形 / 折线 / 面积 / 散点 / 直方 / 核密度 / 箱线 / 饼 / 热力）：编码列、同类别聚合方式、分箱数、Top N、排序方式都可调，图表**直接读当前变换结果**，配色跟随亮 / 暗主题；
- **数据体检**（`df.info()` / `df.memory_usage(deep=True)` 的可视化）：每列 dtype / 缺失 / 唯一值 / 占用字节，并估算 `astype("category")` 能省多少；**显示设置**（`pd.set_option("display.max_rows" / "display.precision")`）改完预览立刻跟着变；
- **6 份内置数据集**（销售流水 / 学生成绩 / 国家指标 / 城市月度气候 / 股票日线 / 员工信息，共 1235 行）由固定随机种子在前端生成，另可用**文件 / 粘贴 / 网址**载入自己的 CSV / TSV / JSON（粘贴一段 HTML 表格也能读，`read_html` 的迷你实现）；
- **导出**：结果 `CSV` / `JSON` / `HTML 表格` / `SQL 建表`、图表 `CSV` / `SVG` / `PNG`、代码 `.py` —— 文件名跟着当前数据集走，例如 `sales-result.csv`、`sales-chart.svg`、`sales-pandas.py`；
- **顺手的工作流**：**一键预设**（6 个常见分析）、**撤销 / 重做**（按钮 + `Ctrl/⌘+Z`、`Ctrl/⌘+Shift+Z`）、**分享链接**（数据源 + 步骤 + 图表编码打进 `#pd=`，打开即还原）、**结果表分页**（12 / 25 / 50 / 100 行每页，导出仍是全量）、**复制到剪贴板**（结果 CSV / TSV / Markdown 表格 —— 复制 TSV 再粘回粘贴框就等于 `read_clipboard()` 往返）；
- **零依赖、零外链**：没有 npm、没有 CDN、没有第三方图表库 —— 迷你 DataFrame 引擎（`pandas.js`）与图表引擎（`charts.js`）都是本仓库的手写实现；
- **可访问性与窄屏兜底**：`skip-link` 跳转链接、`<noscript>` 文字说明、`aria-pressed` / `aria-expanded` 状态、**每张图都有等价的数据表**、顶栏在窄屏折叠成抽屉（Esc 收起并把焦点还给汉堡按钮）。

> 配套自检：`node selfcheck.mjs` —— 一条命令跑完 **128 项静态自检**（语法 / 页面结构 / 中英词表 / 选择器契约 / 样式契约 / 引擎与数据 / 文档数字），毫秒级返回，不联网、不开浏览器；
> 加上 `--full` 会连**真机冒烟**（`smoke.mjs`：真实 Chrome + CDP，**436 项交互断言**）一起跑。
> 本文档「复杂度清单」里的数字由 `selfcheck.mjs` 的第 ⑦ 节**逐行核对** —— 数字过期会直接变红，不靠人记。

## 🛠 技术要点

- **运行时零构建、零依赖**：没有 `package.json`、没有打包器，`index.html` 直接引用相对路径的 `.js` / `.css`；
  加载顺序固定为 `theme.js → pandas.js → charts.js → data.js → i18n.js → app.js`，`theme.js` 放在 `<head>` 里提前执行以避免暗色闪白。
- **引擎与界面分离**：`pandas.js` 只管「表」，`charts.js` 只管「画」，`app.js` 只管「把表画进页面并接管交互」，
  `data.js` / `i18n.js` 则是纯数据与词表 —— 所以同一个引擎可以同时喂预览表、结果表、图表与代码生成四路输出。
- **列名英文、文案双语**：列名统一用 `order_id` / `units` 这样的英文标识符，生成的 pandas 代码可以直接复制去跑；
  界面文案走词表，两种语言看到的是**同一份数据、同一段代码**。
- **颜色一律从令牌取**：`charts.js` 通过 `getComputedStyle` 读 `tokens.css` 的 `--c-*` 变量，再写成 SVG **表现属性**（而不是 CSS 类）——
  好处是①切主题时颜色自动跟随、②导出的 SVG / PNG 脱离页面也不掉色。
- **主题 / 语言切换 = 重画**：`themechange` 与 `langchange` 事件都触发同一套 `renderAll()`，状态（数据源 / 步骤 / 图表编码）保持不变。
- **代码是「拼」出来的，不是抄的**：每个算子自带一个 `code(params)` 片段，`app.js` 把它们按顺序拼成
  「读取 → 变换 → 画图 → 导出」整段脚本，因此**页面显示、复制的代码、下载的 `.py` 永远是同一份**（`smoke.mjs` 逐字比对）。
- **错误隔离**：某一步的参数不合法（例如没选列）只会把这一步标红并把原因写成图注，其余步骤照常计算，结果回落到能算出的那一步 ——
  不会因为一个空参数把整页弄崩。
- **空结果不画假图**：结果 0 行时图表区不画 SVG、图表数据表也归零，而不是留下一张空坐标系。
- **撤销 / 重做是一摞快照**：每次真正的改动（加步骤 / 改参数 / 改图表编码 / 换数据源）都把「步骤 + 图表编码 + 当前数据源」序列化入栈，连续拖同一个参数按 700ms 合并成一条；
  快捷键与两个按钮读写同一份栈，按钮的可用状态跟着栈位走，所以「撤销」永远不会出现「按了没反应」。
- **预设是声明式的小流水线**：每个预设只声明「用哪些算子 + 图表怎么编码」，参数**按当前表的列现算**（类别列 / 数值列 / 日期列），因此换一份数据集照样能套，套完还能继续手动加步骤。
- **分享链接用地址栏当载体**：`#pd=<base64(JSON)>` 里只装「还原得出来」的最小信息 —— 内置数据集记 `id`，自建数据连原始文本一起带走（超过 2400 字符就拒绝生成并劝去导出 CSV）；
  页面载入时先试还原，成功就跳过灌默认数据集，失败则忽略并给出一行提示。
- **数据体检按 pandas 的口径算内存**：int64 / float64 / datetime 8 字节、bool 1 字节、object 是「指针 + UTF-16 字符」、category 是「编码数组 + 类别目录」（`pandas.js` 的 `colBytes`），
  所以「转 category 能省多少」是可复算的，不是拍脑袋的百分比。
- **无障碍**：跳转链接、`<noscript>` 文字说明、导航 `aria-expanded` / 图表类型 `aria-pressed`、`<label for>` 与控件一一对应、
  所有 `aria-*` 引用的 id 都真实存在（`selfcheck.mjs` 静态断言）。
