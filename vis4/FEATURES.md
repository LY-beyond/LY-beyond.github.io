# 《可视化导论》课程门户 · 核心亮点

> 中国石油大学（华东）《可视化导论》课程项目门户（vis4）。
> 纯静态、零构建、零 CDN 依赖，中英双语镜像，深色模式默认。

---

## 一、项目定位

以「先看懂数据是什么，再决定用什么图形表达」为主线的可视化学习门户。围绕陈为《可视化导论》教材，把 **5 章 27 小节** 的内容拆解为可运行演示 + 原理示意图 + 决策工具 + 自测题库，所有学习数据仅保存在本机浏览器（localStorage），不依赖任何后端。

---

## 二、内容体系

| 模块                          | 说明                                                                                                        |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **5 章正文**            | 数据 → 可视化流程 → 色彩专题 → 低维数据 → 时序数据，每章配原理示意图与可运行 Demo                       |

## 三、基础体验

- **中英双语镜像**：`/` 与 `/en/` 两套页面结构完全一致，复用同一套脚本与设计令牌。
- **深色模式默认 + 无闪屏**：首次访问默认暗色；主题切换脚本在 `<head>` 阶段同步写入 `data-theme`，渲染前即确定主题，避免白屏闪烁；偏好持久化到 localStorage。
- **连续阅读**：章节页顶部学习路径带可点击锚点，小节进度自动记忆，首页 Hero 按钮自动定位到「正在读但没读完」的章节。
- **学习进度记忆**：小节阅读、学习目标勾选、测验成绩全部写入 localStorage，跨会话保留。

## 四、知识图谱的物理交互

采用 `d3-force` 力导向布局，对齐 vis2 关系图谱的交互手感：

- **邻接吸引 + 非邻接排斥**：拖动任一节点时，相连节点被弹簧吸引跟随，未相连节点被电荷排斥远离，力在网络中真实传播。
- **仅临时固定被拖节点**：初始化时不钉死任何节点，只在拖拽瞬间用 `fx/fy` 临时固定当前节点，保证力能传到邻接节点。
- **位置持久化**：松手后节点位置保留。
- **健壮性兜底**：`setPointerCapture` 包裹 try/catch、4px 位移阈值防抖手抖、窗口失焦自动释放避免节点卡死。

## 五、三大创新功能（本轮新增）

### 1. 全站 CVD 色觉模拟开关

让任意页面都能以红绿色盲 / 绿色盲 / 蓝色盲的视角浏览，是面向**包容性设计**的教学工具。

- **实现**：`theme.js` 在 `<head>` 阶段向 `<html>` 注入 SVG `<feColorMatrix>` 滤镜定义，`html[data-cvd]` 通过 `body { filter: url(#cvd-*) }` 全站生效。矩阵与第 3 章 CVD 演示同源（Machado 2009 一类近似）。
- **交互**：顶栏眼睛图标按钮循环切换 `关闭 → 红色盲 → 绿色盲 → 蓝色盲`，状态写入 `vis4-cvd`，多标签页通过 `storage` 事件实时同步。
- **零闪屏**：滤镜定义在 `data-cvd` 属性生效前注入，避免引用悬空导致页面空白。

### 2. 个人学习画像（首页 #profile）

首页新增「我的学习画像」卡，把零散的学习记录汇总为可视化反馈：

- **五维掌握度雷达**：每章得分 = `小节阅读 50% + 学习目标 30% + 测验表现 20%`；某章无测验数据时自动折算为 `5/8 + 3/8`。测验扣分依据错题本的 `chapter` 字段按章计算。
- **18 周学习热力图**：由 `vis4-activity`（`{YYYY-MM-DD: count}`）驱动，`progress.js`（小节/目标）与 `quiz.js`（答题）双写埋点，保证任一学习动作都被记录。
- **数据闭环**：所有数据来自 localStorage，无后端；空状态引导用户从第 1 章开始。

### 3. 错题深链重练闭环

打通「测验 → 画像 → 重做」的学习闭环：

- 测验提交时错题写入 `vis4-quiz-wrong`（含 `chapter` 字段），历史成绩写入 `vis4-quiz-history`。
- 首页画像卡提供「重练错题」按钮，直达 `quiz.html#review` 自动启动错题重做模式；`quiz.html#wrong` 直接打开错题本。
- 错题重做仅抽取答错题目，重做正确后从错题本移除，形成复习闭环。

## 六、技术实现

- **设计令牌 `tokens.css`**：颜色、间距、字号、圆角、章节色系统一抽象，深浅双主题与全站组件复用同一套令牌，无硬编码色值。
- **零构建 / 零 CDN**：D3 等依赖本地化至 `vendor/`，无 `package.json`、无构建步骤，任意静态服务器即可部署。
- **SVG 增量更新**：知识图谱渲染使用增量更新而非 `innerHTML` 重建，DOM 引用缓存避免交互时反复 `querySelectorAll`。
- **路径动画**：`pathLength="1"` 归一化，`dashoffset` 过渡无缝。
- **无 `requestAnimationFrame` 依赖**：交互与动画避免在后台标签页/无头环境下出现不一致行为。
- **可访问性**：`skip-link` 跳至主内容、ARIA 标签、语义化结构；顺手修复了 `.btn` / `.progress-line` 的 `display` 覆盖 `hidden` 属性的隐患。

---

## 七、小结

本门户在「教材内容可视化」的基础上，叠加了三层设计：

1. **教学内容层**：5 章 27 节 + 演示 + 选图指南 + 自测 + D3 工作台；
2. **交互体验层**：力导向知识图谱、连续阅读、进度记忆；
3. **创新功能层**：全站 CVD 色觉模拟、个人学习画像（雷达 + 热力图）、错题深链重练闭环。

全部功能遵循「纯静态、纯本地、零依赖」的工程约束，双语与双主题一致，可直接用于课程答辩与教学演示。
