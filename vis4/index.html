学习路径

按顺序走完这 5 步，你会从「把数据读进浏览器」一路走到「为不同粒度的时间数据挑对图形」。每一步都写明学完能做什么——点节点直接进章节。

已读 0 / 27 小节
  1. 01 数据 把现实世界装进一张表格 学完能 看一列数据就知道它是「名字」还是「数值」，并选中合适的视觉通道去表达它。
  2. 02 数据可视化流程 从原始数据到屏幕上的图 学完能 说清「原始数据 → 数据表 → 视觉结构 → 视图」每一步到底做了什么、在哪一步出错。
  3. 03 色彩专题 颜色不是装饰，是一个通道 学完能 为任意图表挑出一套可读、色盲友好、能通过对比度检查的配色。
  4. 04 低维数据可视化 二维平面上的全部技巧 学完能 在一张图里同时编码两个变量、一条趋势和若干离群点，并判断读图误差从哪来。
  5. 05 时序数据可视化 时间是最常见的维度 学完能 为不同粒度的时间数据（时刻 / 区间 / 周期 / 跨度）选择日历、螺旋或故事线。

CHART CHEAT SHEET

图表速查：先问任务，再挑图形

右侧这一列是最常被误用的地方。挑图形的第一步不是「哪个好看」，而是「我的数据类型允许哪些视觉通道」。

速查矩阵：按「想表达什么」反查图表（完整版含 20 行、交互决策树、正误用图对照与 6 题小测，见《选图指南》专题页）
你想表达 推荐图表 主要视觉通道 慎用 / 常见错误
比较若干个类别的大小 条形图 长度（位置） 别用面积 / 体积表达大小；类别多时按数值排序
看一个变量的分布形状 直方图 / 密度图 长度（分箱计数） 分箱宽度决定形状，换宽度会「换一个故事」
看两个变量的关系 散点图 位置（x, y） 点重叠时先设透明度，或换六边形分箱
看随时间的趋势 折线图 位置 + 斜率 时间轴必须等距、连续；不要给无序类别画折线
看构成与占比 堆叠条形图 长度（可比较总长） 饼图超过 5 个扇区就读不出差值；扇区要按大小排序
看二维密度 / 相关强度 热力图 颜色亮度（顺序型 colormap） 别用彩虹色阶；必须有颜色图例
比较多组分布并找离群点 箱线图 / 小提琴图 位置 + 长度（统计量） 样本量很小的组不要画箱线图，直接画点
看多变量之间的整体结构 散点矩阵 / 平行坐标 位置（多轴） 维度超过 8 个要换降维（PCA）或分面

ABOUT

关于本课程

📖 理论来源

陈为《可视化导论》；Mackinlay 1986（视觉通道排序）；Stevens 1946（测量尺度）；Cleveland 1984（图形感知）；Card 1999（数据流模型）；Bostock 的 D3 官方文档。

🎯 设计原则

案例为中心，不是理论为中心。每个知识点都嵌在实践案例里，配 ⭐ 关键点解释、可运行演示与即时自测。

🧭 怎么学

① 章首先勾学习目标；② 按小节连续往下读，演示会就地渲染；③ 用「只看代码」开关快速复习；④ 做完每节自测再看下一节。

🛠️ 技术栈与约束

零构建：纯 HTML + CSS + ES Modules + 本地内置的 D3 模块，不含任何视频。所有原理示意图都用内联 SVG 绘制，整站体积可控、离线可用。

🗂️ 附录 · 可视化原始标本

附录页收编了课程原有的全部独立演示与第 4 章讲义 PDF：保留原生 D3 写法，先读正文，再来对照源码。
