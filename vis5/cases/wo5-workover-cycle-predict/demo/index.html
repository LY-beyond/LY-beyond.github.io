β、η 由影响因素加权推算，见页脚公式

模型公式：工况严苛度 H = 0.28·出砂 + 0.16·含水 + 0.16·泵挂 + 0.12·冲次 + 0.28·腐蚀（各归一化 0–1）；工艺缓解 M = 0.55·防砂·min(1.4·出砂,1) + 0.45·防蜡防腐·min(0.7·(含水+腐蚀),1)；β = clamp(2.3 − 1.6·H + 0.4·M, 0.7, 2.8)；η = clamp(620·(1 − 0.58·H)·(1 + 0.42·M), 120, 1100) 天；故障后更换成本 Cf = 1.8·作业费 + (6+8H)·日损失（抢修加价 + 非计划停井更长），计划检泵 Cp 含停井 2 天损失；C(T) 分母 ∫₀ᵀR(t)dt 为期望有效运行天数。
