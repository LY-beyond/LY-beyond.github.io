拖动即时重算
升温加深裂化：气体↑、RON↑，过高汽油过裂化
剂油比↑转化率↑，但再生器负荷↑
回炼比↑单程转化率↓，油浆↓
残炭↑焦炭↑、油浆↑，再生温度压力大
密度大原料变重，可裂化性下降
馏程越重，转化率越低、油浆越多
ASTM D3907 口径；活性↓转化率与汽油↓
再生温度约束 ≤ 715 ℃（典型 680—700 ℃）

代理模型：转化率 X = 66 + 0.9·(T−505) + 3.0·(C/O−6.5) − 9·(回炼比−0.2) + 0.55·(MAT−66) − 1.5·(CCR−2) − 40·(ρ−0.915) − 0.10·(T50−420)，截断 50—92%；汽油 = 1.2X − 0.008X²（拐点 X=75%，过裂化下降），干气 = 0.07X − 1.6 + 0.03(T−505)，液化气 = 0.34X − 10.2 + 0.09(T−505)，油浆 = (100−X)·(0.20+0.03·CCR)，柴油 = 未转化 − 油浆，焦炭 = 0.075X + 0.5·CCR − 0.9 − 0.02(T−505)，六类 + 0.5% 损失归一闭合至 100%；RON = 88 + 0.10(T−505) + 0.05(X−66) + 0.15(MAT−66)；再生温度 = 630 + 12·焦炭 + 4·(C/O−6.5) + 1.5·CCR，约束 ≤ 715 ℃。
