集总代理模型：层系有效增量 ΔE = Σ(实注ᵢ − 现状ᵢ)·ηᵢ（η：Ed1 0.62 / Ed2 0.30 / Ed3 0.95 / Ed4 0.70，高渗层注水效率低、低渗剩余油层高）；产油增量 = 0.0275%·ΔE，爬坡 1−e^(−t/1.8)；含水上升率 = 2.8 − 0.0025·(现状Ed2−实注Ed2) − 0.0011·(实注Ed3−现状Ed3)；存水率 = 41 + 0.0095·(现状Ed2−实注Ed2) + 0.004·(实注Ed3−现状Ed3) + 0.0004·Δ实注；基线产油 465 t/d、月自然递减 0.8%。模型仅演示趋势，数值以案例验收口径（季度增油 +4.2%、含水上升率 1.9%/年、存水率 44.4%）为准。

③ 指标定义：存水率 / 含水上升率 / 注采比（行业标准口径）

本案例验收指标的计算依据
行业标准 SY/T 6366-2005《油田开发主要生产技术指标及计算方法》（2005-07-26 发布、2005-11-01 实施，全部代替 SY/T 6287-1997 与 SY/T 6366-1998）：规定水驱油田开发主要生产技术指标的取值规定、计算方法、参数符号及计量单位，常规注水油田适用，其他类型油田可参照执行。 标准信息↗
指标定义 / 公式本案例数值
存水率 ESES = (Wi − Wp) / Wi = 1 − Wp/Wi（地下存水量 ÷ 累积注水量），表征注水利用率人工调配 41% → 本方案 44.4%（+3.4 个百分点）
水驱指数注入水地下存水量 ÷ 累积产油量地下体积随存水率同步改善（降低无效水循环）
含水上升率每采出 1% 地质储量含水率的上升值（dfw/dR）；工程上也按年化含水升幅考核2.8%/年 → 1.9%/年（目标 ≤2.0%/年）
注采比注入地下体积 ÷ 采出地下体积（注采井数比 = 注水井总数 ÷ 采油井总数）1.05（24 注 / 58 采 ≈ 0.41 井数比）
存水率公式出处：《萨北开发区阶段存水率和水驱指数变化特征研究》（石油地质与工程）给出同口径定义——存水率 =（累计注水量 − 累计产水量）÷ 注水量，水驱指数 = 地下存水量 ÷ 产油量，二者为高含水期注水效果评价的核心指标（期刊 PDF↗）。
