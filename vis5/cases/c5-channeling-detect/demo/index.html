API RP 10B-2 口径

数据口径：窜槽路径四类——水泥环内部通道、套管-水泥界面、水泥-地层界面、微环隙；气窜条件 = 欠平衡压力 + 通道；隔离液紊流接触时间 ≥ 10 min（API RP 10B-2）；静切力 48→240 Pa 为气窜敏感期。井段 1200—1500 m，水泥浆密度 1.90 g/cm³，气层位于井段底部。

模型公式：顶替效率 η = 0.55 + 0.3·(1−e^(−接触/10)) + 0.1·(1−偏心) + 活动加成(0/0.08/0.05)，上限 0.98；残留泥浆弧长 = (1−η)·360·(1+偏心/50)；窜槽概率 = sigmoid((残留弧长−120)/40)；气窜驱动力 = 气层压力 − 水泥浆静液柱压力。
