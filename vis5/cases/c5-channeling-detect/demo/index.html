⑥ 顶替与地质参数（12 项）

拖动即时重算
邻接参数联动：已同步 0 个共享参数（偏心/排量）
偏心越大，窄边水泥环越薄
占井段比例，通道向下延伸
通道在环空圆周占据的角度
通道径向开度，决定过流面积
API 建议湍流接触 ≥ 10 min
排量不足时泥浆残留窄边
屈服值越高，顶替临界排量越大
旋转/往复可破坏窄边滞留环
套管-水泥界面贯通缝隙
与水泥浆静液柱压力比较
静胶凝强度 48→240 Pa 过渡期
累积气窜量的观察截止时间
井段 1200—1500 m · 水泥浆密度 1.90 g/cm³ · 气层位于井段底部

模型公式：顶替效率 η = 0.55 + 0.3·(1−e^(−接触/10)) + 0.1·(1−偏心) + 活动加成(0/0.08/0.05)，上限 0.98；残留泥浆弧长 = (1−η)·360·(1+偏心/50)；窜槽概率 = sigmoid((残留弧长−120)/40)；气窜驱动力 = 气层压力 − 水泥浆静液柱压力。
