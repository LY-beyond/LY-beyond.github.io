模型公式（示范口径）：穿深折减 Lp = Lp₀·10^(3.7×10⁻⁵·(6500 − UCS_psi))（Thompson 1962）；表皮 S_p = S_h + S_v + S_wb，S_h = ln(r_w/r_w′(θ))，r_w′ = α_θ·(r_w + Lp)，S_v = 10^a·h_D^(b−1)·r_pD^b，S_wb = c1_θ·e^(c2_θ·r_wD)，系数见「真实数据来源」页（Karakas & Tariq 1991）；产能比 PR = ln(r_e/r_w) / (ln(r_e/r_w) + S_p)，r_w = 0.108 m、r_e = 250 m、k_h/k_v = 10；出砂指数 = (Δp / (0.32·UCS^0.85))·(孔密/16)^0.85·(10/k)^0.25·(1+(120°−θ)/500)，≥1.0 判为高风险；应力集中指数以 16 孔/m、700 mm、90° 为基准 1.0。注：示范用垂井简化口径，仅演示参数联动趋势；工程口径为水平井三维供流模型。
