GB/T 958-2015 图例口径

数据口径：合成图幅按 1:20 万区域地质图结构生成：6 个地层单元（C2b / J3t / K1d / K2s / E1h / Q）、3 条断层（正 / 逆 / 走滑，GB/T 958-2015 符号）、8 个产状符号、6 个钻孔；验收口径取自案例设定：要素级 F1 ≥ 0.85、拓扑完整率 ≥ 90%、属性正确率 ≥ 95%（断层线不参与地层多边形闭合）。

② 提取流水线参数（4 项）

拖动即时重算
低于阈值判为不可靠；过低混入误检，过高漏检小符号
断层整体偏移约 2.5 px：容差 < 3 px 时断层匹配率骤降
过小：相似地层单元合并丢界线；过大：单元内过度分割
过滤碎线；本区 40% 断层 < 2 km，过大将误删小断层
推荐区间：阈值 0.6–0.75 · 线宽 ≥ 3 px

仿真口径：每个真值要素带固定置信度（0.45–0.97）；线宽容差 < 3 px 时断层匹配置信度折减、< 2 px 时界线折减；颜色容差 < 25 时两组相似地层界线丢失、> 45 时产生过度分割误检；长度 < 最小图元长度的线段直接滤除。误检源：等高线 2 条、图例框色块 1 处、注记笔画 1 处（未做版面切分的典型陷阱）。拓扑完整率 = 61% 基线 + 界线长度加权召回增益 − 误检惩罚。

国家标准 GB/T 958-2015 配套用色规范 ·《地质图用色标准》（1:500 000～1:1 000 000，报批稿公示）：按年代地层单位设色、岩石花纹叠加原则。本 demo 地层色块按「年代越新色越浅」原则用主色调制。对应模块：地层色块分割、颜色容差参数的物理意义。 公示稿↗
