评分模型：score = σ(3.2·log₁₀(TG/滚动基线) + 1.0·组分同步度 + 0.6·钻时减慢度 − 1.1)，接单根段泵状态置位时强制压为背景；校正口径 TG_corr = (TG_raw/(k_Q·k_η) − 基线)/k_ρ + 基线，k_ρ = 1−0.4·(ρ−1.85)/0.35，k_Q = 30/Q，k_η = η/75。流体判别：C1 占比 ≥95% 且 Wh<4%（全烃低、几乎纯 C1）→ 水层；Wh ≥17.5% → 气水同层（湿气）；其余 → 气层；段内 ≥50% 采样点为接单根标记 → 假异常。置信度 =(0.5×段均分+0.5×段内峰值分)×(0.85+0.15×组分同步度)。
