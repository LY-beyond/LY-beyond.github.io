概率 ≥ P* 圈为异常；过高漏弱异常，过低误报多
点稀则插值把窄异常带抹成宽而淡的晕
化验与地表扰动噪声，越大弱异常越难识别
盐沼背景可比戈壁高 3 倍；不分区归一则整片误判
含油气概率先验：构造高点 / 断裂交汇加权
剖面切过环状异常（y≈6）或盐沼区（y≈4）
区块 24×15 km ≈ 360 km² · 网格 0.25 km

模型口径：分区稳健归一 z = (ln v − ln 背景中位数) / (1.3σ+0.18)；融合得分 = Σwᵢzᵢ（吸附烃 0.22 / 酸解烃 0.20 / ΔC 0.18 / 热释轻烃 0.16 / 土壤汞 0.14 / 重烃、荧光各 0.05）；概率 P = sigmoid(4.5·(得分−0.58) + 2.2·先验·构造邻近度 − 0.2)；异常聚类 = P≥P* 网格连通域（近似 DBSCAN ε=1.2 km 效果）；分级 Ⅰ类 Pmax≥0.8 / Ⅱ类 ≥0.6 / Ⅲ类 其余；形态按「中心概率 < 0.7×环带均值」判环状。人工对照 = 吸附烃单指标、全区中位数+2σ、不分区。本页为教学演示模拟数据。
