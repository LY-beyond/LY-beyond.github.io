API RP 10B-2 口径

数据口径：API RP 10B-2 抗压强度；钻开水泥塞前须 ≥ 500 psi (3.45 MPa)；井口试压 ≥ 1500–2000 psi；典型 24h UCS 14–21 MPa，7d 35 MPa；高温 > 110℃ 须加硅粉 30–40% 防强度倒缩；强度发展 UCS(t) = UCS_ult·(1−e^(−(t/τ)^p))。
