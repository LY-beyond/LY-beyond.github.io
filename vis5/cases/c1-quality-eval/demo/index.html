数据口径：CBL 自由套管幅度 FPA≈320 mV；相对幅度 ≤20% 为优(A)、20%–30% 为中(B)、>30% 为差(C/D)；胶结指数 BI = 1 − amp/FPA，BI>0.8 合格；衰减率(dB/ft)越高胶结越好；VDL 套管波早到、地层波晚到。参考 API RP 10B-2 / SY/T 6646。
