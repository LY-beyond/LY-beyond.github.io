数据口径：API Class G 水泥净浆基准水灰比 0.38、密度 1.89 g/cm³、24h UCS 14–21 MPa；稠化时间以 70 Bc 为终点；API 失水 ≤ 50 mL/30min；静切力 100→500 lbf/100ft² 过渡 < 45 min；自由水 ≤ 1.4%；沉降密度差 ≤ 0.01 g/cm³；ECD 须落在孔隙–破裂压力窗口内。参考 API RP 10B / API 10B-2。

水泥浆配方智能优化

调节密度、水灰比、外加剂与温度，实时查看稠化时间、流变性、失水、强度与 ECD 压力窗口，下方体检卡对每项指标给出 PASS/FAIL。

① 稠化时间曲线

横轴为时间(min)，纵轴为稠度(Bc)。曲线在 70 Bc 处的时间即为稠化时间 t₇₀；竖线为设计施工时间，二者之差为施工余量。

② 流变曲线

幂律模型 τ = τy + K·γⁿ。横轴剪切率 γ (s⁻¹)，纵轴剪切应力 τ (Pa)。n 越小越剪切稀释，K 越大黏度越高。

③ ECD 沿深度剖面

横轴为当量密度(ppg)，纵轴为井深(m)。两条横线分别为孔隙压力梯度与破裂压力梯度；ECD 斜线须落在二者之间，红色段为越界。

⑥ 方案对比 · 帕累托前沿
