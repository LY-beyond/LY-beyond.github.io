区块背景

松辽盆地某老区开发 22 年，118 口生产井、单井历史 1,800–8,000 天；近 3 年措施 156 井次（压裂 41、堵水 63、酸化 52），注水井 34 口。此前配产靠 Arps 拟合（全井 MAPE 13.6%，措施井 27.4%）；TCN + 事件脉冲通道模型（540 天窗口、跨井 pooling）把全井 90 天 MAPE 压到 8.2%（正常井 6.9%、措施井 14.1%），归因增油与动态分析结论符合率 83%，配产编制从 1 周缩到 2 h + 半天复核。

模型公式（示范口径）：真实序列 q(t) = q₀·e^(−Dt)·Π(1+f_i·e^(−(t−t_i)·δ_i))·(1+g·(1−e^(−(t−t_r)/τ)))（措施脉冲 + 注水滞后见效）；Arps 参考 = 对预测起点前 240 天历史做指数递减最小二乘拟合后外推；模型预测 = 无措施反事实基线 + 措施计划协变量贡献（低估系数 0.88、响应时移 +2 天）；置信带半宽 w(h) = (0.035+0.085·h/90)·z(置信水平)/1.645·(1+0.6·措施强度)；措施归因 = 反事实对比（屏蔽事件通道）逐日积分。注：演示井例为确定性模拟数据，仅演示预测与归因的联动趋势；工程口径为 TCN + 事件脉冲通道、分位数归一与跨井 pooling。

① Arps 递减模型：三种递减类型（1945 年原文公式实时计算）

递减分析的工业标准基线 · 本案例 Arps 参考线即此口径
经典文献 Arps J.J. (1945), "Analysis of Decline Curves", Trans. AIME 160(1):228–247（SPE-945228-G）：提出指数（b=0）、双曲（0<b<1）、调和（b=1）三种递减模型 q = q_i/(1+b·D_i·t)^(1/b)。Fetkovich M.J. (1980), "Decline Curve Analysis Using Type Curves", JPT 32(6):1065–1077（SPE-6849-PA）：把 Arps 经验式与定压生产理论解统一，证明指数递减是边界控制流（BDF）的长期解，双曲图版族 b 取 0–1。 DOI↗
指数递减 b=0 双曲递减 b=0.5 调和递减 b=1 归一化 q/q_i，D_i = 0.8 /年（示意）
递减模型b 值公式典型适用
指数递减b = 0q = q_i·e^(−D·t)定容消耗、边界控制流长期解（Fetkovich 1980）
双曲递减0 < b < 1q = q_i·(1+b·D_i·t)^(−1/b)水驱 / 溶解气驱油藏最常见
调和递减b = 1q = q_i·(1+D·t)^(−1)双曲特例，强水驱或重力驱后期

② 双曲递减指数 b 的取值区间与工程判读

悬停色带读数 · 金色括线 = 本案例 118 井拟合 b 中位区间
经典文献 Fetkovich (1980, SPE-6849-PA)：Arps 图版族 b ∈ [0,1]，拟合应限于边界控制流段；Ilk D., Rushing J.A., Perego A.D., Blasingame T.A. (2008), "Exponential vs. Hyperbolic Decline in Tight Gas Sands", SPE-116731：致密气藏常拟合出 b>1，属瞬态流段特征，按双曲外推会系统性高估 EUR，建议改用指数或分段模型——这正是本案例「措施/突变后 Arps 失效」的理论镜像。 DOI↗
b 区间判读工程含义本案例处置
b = 0指数递减定容消耗、BDF 长期解正常递减井基线，月度误差 ≤10%
0 < b ≤ 0.5常见双曲段水驱 / 溶解气驱油田拟合最常见区间本案例 118 井拟合中位 b ≈ 0.42
0.5 < b < 1双曲段强非均质、重力/弹性驱动贡献逐井拟合，超限复核
b = 1调和递减双曲特例（Arps 1945）仅作图版对照
b > 1瞬态流段标志Ilk et al. 2008：外推高估 EUR判为无效拟合，切换事件协变量模型

(2025), "Production Prediction for Shale Oil Horizontal Wells Using CNN–BiLSTM", ACS Omega 11(1):2206–2220：鄂尔多斯盆地长 7 段页岩油 42 口水平井，CNN–BiLSTM 实测 MAPE 3.2333%、RMSE 0.3103、MAE 0.1731、R² 0.8856，优于 SVR / RF / XGBoost / LSTM / BiLSTM 五种对照。Idris M.H.A. et al.
