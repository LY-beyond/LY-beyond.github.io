## 1. 阶段一 · 套管下入

### 1.1 专业背景

固井的前置工序。钻至设计井深后起出钻具，下入**套管串**（casing string），套管底部装**浮鞋**（float shoe，单向阀防泥浆倒灌），其上 1~2 根装**浮箍**（float collar，承托胶塞）。套管外壁按间距装**扶正器**（centralizer）使套管在井眼内居中，否则注水泥时高边易形成泥浆窜槽。

下入过程需控制下放速度，防止**激动压力**（surge pressure）压漏地层；下到底后先循环洗井，调整泥浆性能，为注水泥做准备。

### 1.2 可视化数据 / 参数

| 参数 | 典型值 | 来源 |
|------|--------|------|
| 套管串底部结构 | 浮鞋 + 浮箍（浮箍在浮鞋上方 1~2 根套管） | SLB Defining Cementing [P1] |
| 扶正器作用 | 保持套管居中，避免高边窜槽 | SLB [P1] |
| 激动/抽吸压力 | 下放过快 → 漏失；起钻过快 → 溢流 | 通用钻井水力学 |

### 1.3 可可视化元素
- 套管柱：浮鞋（底部圆头+单向阀符号）、浮箍、扶正器环
- 井眼内泥浆循环箭头
- 压力计读数（激动压力）

## 2. 阶段二 · 注水泥封固（双胶塞工艺）

### 2.1 专业背景（SLB 官方定义）

SLB《Well Cementing Fundamentals》给出的标准**双胶塞一次注水泥**流程：

1. **化学清洗液 + 隔离液**（wash + spacer）—— 泵入套管内，顶替泥浆
2. **下胶塞**（bottom plug，带破膜）—— 刮净套管内壁泥饼，隔离泥浆与水泥
3. **水泥浆**（cement slurry）—— 设计体积，填满环空
4. **上胶塞**（top plug）—— 隔离水泥与顶替液
5. **顶替液**（displacement fluid，一般为泥浆或水）—— 推上胶塞下行
6. **碰压**（bump pressure）—— 上胶塞座到下胶塞上，地面压力突升，注水泥结束

下胶塞到达浮箍时膜片破裂，水泥通过进入环空；上胶塞座合信号即"碰压"。

### 2.2 量化施工参数（真实井数据）

**QLD Atlas-134 井固井报告** [P0 政府公开数据]：
| 参数 | 值 |
|------|----|
| 平均泵速 | 4 bbl/min |
| 水泥返出体积 | 11.7 bbl |
| 最终泵压 | 260 psi |
| 稳压 | 1500 psi |
| 碰压 | 1240 psi |

**龙 4 井 6026m 尾管固井** [P1 石油钻探技术]：
| 参数 | 值 |
|------|----|
| 循环排量 | 6.5 ~ 7.2 L/s |
| 泵压 | 13 ~ 15 MPa |
| 返出泥浆密度 | 2.28 g/cm³ |

**地热井注水泥泵机组** [P1]：
| 参数 | 值 |
|------|----|
| 柱塞直径 | 76.2 ~ 152.4 mm |
| 最大水力功率 | 150 ~ 370 kW |
| 最大流量 | ~1.3 m³/min |
| 最大泵压 | ≤ 70 bar |

### 2.3 水泥浆配方（API Spec 10A）

| API 等级 | 干水泥密度 | 水灰比 w/c | 浆体密度 | 24h 抗压强度 | 适用 |
|----------|-----------|-----------|---------|-------------|------|
| Class G | 1898 kg/m³ | 0.44 | ~1898 kg/m³ (15.8 ppg) | ~2000 psi | 通用，中深井 |
| Class H | 同矿物，更粗 | 0.38 | ~1970 kg/m³ | ~1000 psi | 深井高温，缓凝需求低 |

**典型领浆配方**（Cap cement）[P2 行业案例]：
`Class G + 16.0% 硅粉 + 1.0% 膨润土`，密度 15.0 lbm/gal (1.80 SG)。

**外加剂功能**：
- 缓凝剂（retarder）：延长稠化时间，深井高温用
- 分散剂（dispersant）：降黏度、提顶替效率
- 降失水剂（fluid loss additive）：API RP 10B-2，防浆体脱水
- 防气窜剂（anti-gas-migration）：过渡态防气体侵入

### 2.4 可可视化元素
- 双胶塞：下胶塞（带破膜）→ 水泥浆 → 上胶塞 → 顶替液 的柱色谱式推进
- 注水泥泵机组（柱塞往复）
- 实时曲线：**泵压**（clay 橙，碰压突升）、**排量**（jade 绿，平稳）、**水泥浆密度**（c-kg 黄绿）
- 套管内泥浆→隔离液→水泥→顶替液 的色带分层流动

## 3. 阶段三 · 声波质量检测（CBL / VDL）

### 3.1 专业背景

固井后下入**声波测井仪**评价水泥环胶结质量。核心工具：

- **CBL**（Cement Bond Log，水泥胶结测井）：发射-接收间距 **0.9 m（3 ft）**，测量套管首波幅度。声能传入水泥/地层则衰减快→幅度低；环空为流体则声能束缚在套管内→幅度高。
- **VDL**（Variable Density Log，变密度测井）：全波形灰度显示，深色=高幅。有地层波到达条纹→第二界面（水泥-地层）胶结好；只有套管波条纹→无地层胶结。

### 3.2 量化判据（AER Directive 009 / WCSB 行业标准）

| 指标 | 完全胶结 | 自由套管 |
|------|---------|---------|
| 套管首波幅度 | 0 ~ 5 mV | 25 ~ 50 mV |
| 胶结指数 BI | 1.0 | 0 |

**BI 公式**：
```
BI = 1 − (实测幅度 / 自由套管幅度 FPA)
```

**分级阈值**：
| BI 区间 | 评价 | 处置 |
|---------|------|------|
| > 0.8 | 良好胶结 | 通过 |
| 0.5 ~ 0.8 | 中等 | 工程评审 |
| < 0.5 | 差 | 考虑挤水泥 |
| 连续 BI < 0.2 超过 5 m | 窜槽 | **强制挤水泥** |

**法定要求**（AER Directive 009）：产层上方 3 m 区间平均 BI ≥ 0.8，单点 BI ≥ 0.6。

### 3.3 第一界面 vs 第二界面

- **第一界面**（套管-水泥）：CBL 幅度直接反映
- **第二界面**（水泥-地层）：VDL 地层波到达条纹确认
- 仅 CBL 低幅但 VDL 无地层波 = "自由水泥"（套管胶结好但未胶结地层），不算有效层位隔离

### 3.4 微环空（micro-annulus）vs 窜槽（channel）

| 特征 | 微环空 | 窜槽 |
|------|--------|------|
| 成因 | 水泥凝固后温/压差收缩，套管-水泥间 0.05~0.5 mm 缝隙 | 顶替不彻底，泥浆残留形成连续流道 |
| 连续性 | 不连续、环向均匀 | 连续、单一方位（高边常见） |
| 鉴别 | 套管加压 **3~7 MPa** 后重新测井，BI 恢复 | 加压无改善 |
| 处置 | 无需处理 | 挤水泥补救 |

标准做法：生产套管 CBL 前加 **3.5 MPa 套压**以闭合微环空，获得真实 BI。

### 3.5 进阶工具
- **扇区 CBL**（4~8 方位）：识别窜槽方位角
- **超声成像**（Schlumberger USIT / Halliburton CAST-V）：0.9°~2° 方位分辨率，5~10 cm 深度分辨率，生成水泥/流体/气体环空分布图

### 3.6 可可视化元素
- 声波探头（c-opt 蓝）沿井筒下放
- 扇形射线：套管波（clay 橙） + 水泥波 + 地层波（c-cv 青）
- CBL 幅度曲线（深度-幅度，jade 绿）
- VDL 变密度灰度条带（地层波条纹=第二界面好）
- 微环空：加压前高幅 → 加压后低幅的状态切换动画

## 4. 阶段四 · 层位隔离评价与失败模式

### 4.1 评价维度

固井质量 = 第一界面胶结 + 第二界面胶结 + 环空完整性，最终目标是**层位隔离**（zonal isolation）—— 阻止产层流体窜入淡水层或地表。

### 4.2 典型失败模式

| 失败模式 | 成因 | 现象 | 可视化 |
|---------|------|------|--------|
| **气窜**（gas migration / annular gas flow） | 水泥"过渡态"（初凝至终凝）期间浆体静液柱压力 < 地层孔隙压力，气体侵入形成通道 | 环空持续套压、产层气体上窜 | clay 橙气流从产层沿水泥环上升 |
| **窜槽**（channeling） | 套管偏心、顶替效率低、泥浆未替净 | CBL 连续 BI<0.2 超 5 m | 高边残留泥浆带（c-nlp 紫） |
| **微环空** | 凝固收缩 / 套压变化 | CBL 假高幅，加压可恢复 | 套管-水泥间细缝 |
| **漏失**（lost circulation） | 环空当量密度 > 地层破裂压力 | 水泥返不到地面，地层吸入水泥 | 水泥浆向裂隙流失 |
| **水泥返高不足** | 顶替量计算偏差 | 水泥顶低于设计 | 环空上部无水泥段 |

### 4.3 补救：挤水泥（squeeze cementing）

- 微水泥 d50 < 6 μm，可进入 0.1~0.5 mm 微窜槽
- WCSB Cardium 案例 [P1]：BI 平均 0.18（2080~2145 m），扇区 CBL 定位 75° 方位高边窜槽，挤入 0.8 m³ 微水泥于 210 kPa，挤后 BI > 0.85，套压 15 天归零

### 4.4 可可视化元素
- 环空状态色带：jade 绿（胶结好）/ clay 橙（气窜）/ c-nlp 紫（泥浆窜槽）/ c-opt 蓝（微环空）
- HUD 数字：第一界面 BI %、第二界面 BI %、水泥返高 m
- 失败模式叠加显示：气窜箭头、窜槽带、漏失裂隙
